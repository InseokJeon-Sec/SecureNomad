# 배포 후 사이트 접속 시 404

## 증상

`https://inseokjeon-sec.github.io/SecureNomad/` 접속 시 GitHub 404 페이지가 표시된다.

## 원인

저장소를 확인해 보니 **`.github/workflows/deploy.yml` 이 GitHub에 올라가지 않은 상태**였다.

- 저장소 파일 목록에 `.github` 폴더가 없음
- Actions 탭에 실행 기록이 없음

워크플로가 없으니 빌드·배포가 한 번도 실행되지 않았고, Pages에 게시된 내용이 없어서 404가 난 것이다.

## 해결

1. `deploy.yml` 이 **프로젝트 최상위**의 `.github/workflows/` 안에 있는지 확인
   (`docs` 안 등 다른 위치에 만들어지지 않았는지)
2. GitHub Desktop에서 Commit → **Push origin** (Commit만 하면 PC에만 저장된다)
3. Actions 탭에서 초록 체크 확인 후 재접속

## 404 점검 순서

| 확인할 곳 | 정상 상태 |
|---|---|
| Settings → Pages → Source | GitHub Actions |
| 저장소 파일 목록 | `.github/workflows/deploy.yml` 존재 |
| Actions 탭 | 최신 실행이 초록 체크 |
| `baseUrl` | 저장소 이름과 대소문자까지 일치 (`/SecureNomad/`) |
| 접속 주소 | 끝의 저장소 이름까지 포함 |

# Sidebar doesn't have anything to be linked to

## 증상

```text
[WARNING] No docs found in "build-log": can't auto-generate a sidebar.
[ERROR] Error: Unable to build website for locale ko.
  [cause]: Error: Docusaurus static site generation failed for 4 paths:
  - "/SecureNomad/404.html"
  - "/SecureNomad/it/overview"
  - "/SecureNomad/security/overview"
  - "/SecureNomad/"
    [cause]: Error: DocSidebarNavbarItem: Sidebar with ID "buildSidebar"
             doesn't have anything to be linked to.
```

## 원인

상단 메뉴(navbar)가 `buildSidebar` 를 가리키고, `buildSidebar` 는 `docs/build-log` 폴더를 자동 생성(autogenerated)하도록 되어 있었는데, **그 폴더에 문서가 하나도 인식되지 않았다.**
연결할 문서가 없는 메뉴가 모든 페이지 상단에 들어가기 때문에 전체 페이지 생성이 실패한다.

## 해결

`docs/build-log/` 안에 `.md` 문서를 1개 이상 만들었다.

점검할 것:

- 폴더가 `docs` 안에 있는지 (최상위에 생기지 않았는지)
- 폴더 이름이 `sidebars.js` 의 `dirName` 과 정확히 같은지
- 파일 확장자가 `.md` 인지 (`.md.txt` 아님)
- VS Code에서 저장(`Ctrl + S`)했는지 (탭의 ● 표시)

## 정리

메뉴를 추가할 때는 **폴더 + 문서 1개 → sidebars.js → navbar** 순서로 만든다.
메뉴를 없앨 때는 navbar와 sidebars.js의 항목을 함께 지운다.

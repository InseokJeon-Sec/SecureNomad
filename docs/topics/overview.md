# Topics

IT 핵심 주제를 **한 토픽씩 깊게 정리**합니다. 개념·원리·비교·적용을 한 장으로 압축해, 빠르게 찾아보고 복습할 수 있게 하는 것이 목적입니다.

## 분류

| 도메인 | 내용 |
|---|---|
| **소프트웨어공학** | 아키텍처, 개발방법론, 품질, 테스트 |
| **데이터베이스** | 모델링, 정규화, 트랜잭션, 분산·신기술 DB |
| **보안** | 암호, 인증·접근통제, 네트워크 보안, 거버넌스 |
| **신기술** | 클라우드, 컨테이너, AI, 빅데이터 등 |
| (네트워크 · 관리 등은 토픽이 쌓이면 추가) | |

## 보는 법

- 왼쪽 사이드바에서 **도메인 → 토픽** 순으로 찾습니다.
- 각 토픽은 **개요 → 구성·원리(도식) → 특징·비교 → 적용 → 결론** 흐름으로 정리됩니다.
- 태그(`기출`, `중요` 등)로 가로로도 모아볼 수 있습니다.

> 토픽은 하나씩 추가해 나갑니다. 각 도메인 폴더에 문서를 만들면 사이드바에 자동으로 나타납니다.

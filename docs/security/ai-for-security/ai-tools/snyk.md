## 개요

Snyk는 **개발 단계에서 코드·오픈소스 의존성·컨테이너의 취약점을 찾아 고치도록 돕는 보안 플랫폼**이다.
AI 엔진(DeepCode AI)을 활용해 코드 취약점을 탐지하고 수정 방안을 제안한다.

앞의 도구들이 공격·진단 중심이라면, Snyk는 **개발자가 코드를 안전하게 작성·배포하도록 돕는 방어용**이다. 개인 개발자도 무료 플랜으로 시작할 수 있다.

## 데이터 처리 관점

클라우드 기반 서비스로, 분석을 위해 코드·메타데이터가 **Snyk 환경에서 처리**된다. 기업 도입 시 데이터 처리·보관 정책과 온프레미스/프라이빗 옵션을 검토한다. <span className="badge badge--amber">클라우드</span>

## 가용성

- 무료 플랜(개인·소규모) + 팀/기업용 유료 플랜의 프리미엄 구조
- IDE·CI/CD·Git 연동 지원

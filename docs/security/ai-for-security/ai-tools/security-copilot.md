## 개요

Microsoft Security Copilot은 **보안 운영(SOC)과 사고 대응을 돕는 생성형 AI 어시스턴트**다.
경보 분석, 사고 요약, 위협 헌팅, 스크립트·쿼리 작성 등을 자연어로 보조하며, Microsoft 보안 제품(Defender, Sentinel 등) 및 외부 도구와 연동된다.

공격·진단이 아니라 **방어자(SOC 분석가)의 업무를 가속**하는 쪽에 특화된다.

## 데이터 처리 관점

클라우드(Microsoft) 기반 서비스로, 분석을 위해 보안 데이터가 Microsoft 환경에서 처리된다. 규제·데이터 주권 요건이 있는 조직은 데이터 처리 위치·범위를 검토해야 한다. <span className="badge badge--amber">클라우드</span>

## 가용성

- 사용량 기반 과금(SCU, Security Compute Unit) 구조의 유료 서비스
- 가격·라이선스 조건은 변동되므로 공식 문서에서 최신 정보를 확인한다.

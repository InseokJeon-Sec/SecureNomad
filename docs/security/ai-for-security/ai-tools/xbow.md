## 개요

XBOW는 **AI가 자율적으로 침투 테스트를 수행하는 상용 서비스**다.
사람이 수행하던 모의해킹을 AI가 "기계 속도"로 대량·빠르게 수행하는 것을 지향하며, 온디맨드(필요 시 수행) 방식도 제공한다.

ARTEX·PentestGPT가 오픈소스 계열이라면, XBOW는 **기업용 상용 SaaS**라는 점이 다르다.

## 데이터 처리 관점

클라우드 기반 SaaS이므로 점검 대상·결과 데이터가 **서비스 제공자 환경에서 처리**된다. 도입 시 데이터 처리·보관 정책을 계약·약관에서 확인해야 한다.

## 가용성

- 상용 서비스. 가격·플랜은 공식 사이트/영업 견적 기준이며 변동될 수 있다.
- AWS Marketplace 등을 통해서도 제공된 이력이 있다.

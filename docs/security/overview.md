## 섹션 바로가기

### 🛡️ [AI for Security](/security/ai-for-security/overview)
AI(Claude)를 **보안 업무의 도구로 활용**한 기록. AI 보안 도구 비교(ARTEX·PentestGPT·XBOW 등)와 취약점 진단 실습(XSS·SQLi).

### 🔒 [Securing AI — AI 보안성 평가](/security/ai-security-assessment/overview)

### 📜 [PKI · 인증서](/security/pki-certificates/overview)
인증서의 **이론과 실무**. 암호·디지털 서명 원리, X.509 구조, Root 인증서와 신뢰 체인, TLS 인증 로직, 수명주기·갱신·폐기, OpenSSL 실무.

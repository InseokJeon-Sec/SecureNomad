# 망연계 솔루션 바로 알기 (망분리·CDS·N2SF)

> **대상 독자:** 솔루션을 검토·도입하는 담당자. 국내 특화 영역입니다. 숫자는 **출처·기준시점**을 함께 표기합니다.

## 1. 망분리 · 망연계란

- **망분리** — 업무망과 인터넷망을 물리/논리로 끊는다. 외부 공격·내부 유출 차단. 금융·공공 **규제 의무**. (물리: PC 2대 / 논리: VDI)
- **망연계** — 분리했어도 자료는 오가야 한다. 두 망을 **직접 연결하지 않고 CDS**(망간 자료전송)를 거쳐 **승인된 자료만** 통과·검사. 방향은 양방향 / **일방향(데이터 다이오드)**.

> 핵심: 직접 연결 없이 중간에서 **끊었다가(스토리지 경유) 검사 후 전달**.

## 2. 동작 — CDS 자료 전송

```text
업무망(전송 요청) → 격리 영역(연결 끊고 임시 저장) → 검사·승인(악성·반출정책·무해화) → 인터넷망(승인분만)
```

CDS는 ‘통로’가 아니라 **검문소** — 끊고, 검사하고, 승인한 것만 넘긴다.

## 3. N2SF 대전환 (18년 만의 개편)

일률적 망분리가 AI·클라우드의 발목을 잡아, 2025년 1월 가이드라인 배포·7월 시행. **망분리 폐지가 아니라 데이터 등급별 차등**입니다.

| 등급 | 의미 | 통제 |
|---|---|---|
| **C** 기밀 | 비공개·최고 민감 | 강한 분리 유지 |
| **S** 민감 | 중요 업무 | 등급별 차등 |
| **O** 공개 | 공개 가능 | 클라우드·AI 활용 허용 |

**CDS의 역할 확대** — 등급 간(도메인 간) 데이터 연계의 핵심 통제. 기존 망연계 → ‘포스트 망연계(CDS)’ 시장. 2026 사이버보안 평가지표에 N2SF 가산점.

## 4. 도입 실무 — 파악 · 생성 · 결정

**① 파악** — 분리 구조(물리/논리), 오가는 자료 유형·빈도, **데이터 등급(C/S/O)**, OT·제어망(일방향 필요 구간), 국정원 검증·CC인증 요구.

**② 생성·준비** — 방향별 CDS, 반출입 승인 워크플로, **무해화(CDR)**·백신 연동, 전송 로그·감사.

**③ 결정** — 양방향 vs 일방향, 등급별 통제 수준, CDR 적용 범위, N2SF 전환 로드맵.

> **일방향(다이오드)이 필요한 OT·제어망에 양방향을 쓰면 유출 통로**가 됩니다. 방향 결정이 핵심.

## 5. 비용·시장 (국내 공공조달)

- 공공조달 중심 **국산 토종 시장**. 국정원 검증·CC인증이 진입장벽.
- **휴네시온** 망연계 공공조달 **47%, 11년 연속 1위**(2015~), 일방향(다이오드) 50%. **한싹·앤앤에스피** 등 N2SF 대응 차세대 CDS. *(출처: ZDNet, 2026-01)*

## 6. 어떤 환경에 맞나

| 상황 | 권장 |
|---|---|
| 공공·공공기관(N2SF 대상) | CDS+등급제 전환 |
| 금융(전자금융 망분리) | 망연계+반출입 통제 |
| OT·제어망·국방 | 일방향(데이터 다이오드) |
| AI·클라우드 도입 희망 | N2SF O등급+CDS 연계 |
| 문서 반입 많음 | CDR(무해화) 병행 |

## 흔한 오해와 함정

- **망연계를 ‘복사 통로’로만** → 검사·승인 없으면 유출·감염 통로
- **방향을 잘못 고른다** → OT엔 일방향 필수
- **N2SF=망분리 폐지 오해** → 폐지 아님, 등급별 차등
- **무해화(CDR) 생략** → 문서 악성요소 그대로 반입
- **등급 분류 없이 전환** → 차등 통제 불가

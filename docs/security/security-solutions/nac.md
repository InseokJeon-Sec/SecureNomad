# NAC 바로 알기 — 네트워크 접근제어

> **대상 독자:** 솔루션을 검토·도입하는 담당자. 숫자는 **출처·기준시점**을 함께 표기합니다.

## 1. NAC이란 — 왜 필요한가

사무실 포트·와이파이에 **무엇이 붙었는지** 모르는 게 가장 큰 위험입니다. BYOD·IoT·방문자·비인가 단말이 섞이고, 하나만 감염돼도 내부 확산의 발판이 됩니다.

**NAC = 네트워크의 문지기.** 모든 단말을 탐지·식별하고, 인증·상태 점검을 통과한 것만 허용하며, 미준수·비인가 단말은 격리합니다.

## 2. 동작 5단계

```text
① 탐지·식별 → ② 인증 → ③ 상태 점검 → ④ 정책 부여 → ⑤ 격리·치료
 (프로파일링) (802.1X·MAC·웹) (백신·패치·암호화) (역할별 VLAN·ACL) (미준수 차단)
```

핵심은 ‘인증’만이 아니라 **상태 점검** — 백신·패치가 안 된 단말은 들어와도 격리합니다.

## 3. 구현 방식 — 세 갈래

| 방식 | 특징 | 비고 |
|---|---|---|
| **802.1X** | 스위치·AP가 포트에서 인증, 표준·강력 | 전 장비 802.1X 지원 필요 |
| **에이전트리스** | 센서·ARP로 설치 없이 탐지·제어 | IoT·레거시에 유리(국내 주류), 단말 내부 통제 약함 |
| **에이전트** | 단말 내부(패치·장치제어·백신) | 상태 점검 정교, 배포 부담 |

→ 실무는 **섞어** 씁니다. 802.1X로 포트 인증, 에이전트리스로 IoT 커버, 에이전트로 단말 통제.

### NAC vs ZTNA

NAC은 **구내망(L2)에 무엇이 붙었나**, ZTNA는 **원격에서 어느 앱(L7)에 닿나**. 경쟁이 아니라 **보완** 관계입니다.

## 4. 도입 실무 — 파악 · 생성 · 결정

**① 파악**
- 스위치·AP의 **802.1X·RADIUS 지원** 여부·레거시 비율
- 단말 인벤토리(수량·OS), **인증 못 하는 기기**(프린터·IoT·OT)
- 인사DB·AD/LDAP·PKI, VLAN·세그먼트·망분리

**② 생성·준비**
- RADIUS 서버·인증서(PKI), 역할·정책 설계
- **MAB 목록**(인증 못 하는 기기의 MAC 등록) — 운영의 핵심
- 에이전트 배포 체계, 게스트·BYOD 포털, SIEM 연동

**③ 결정**
- **모니터 → 강제** 단계 전환 (끊김 사고 대부분이 이 단계 생략에서)
- 격리 방식(VLAN/ACL/치료망), 게스트·BYOD 정책, 예외 기기 처리

> **802.1X를 처음부터 전면 강제하면 프린터·IoT가 끊긴다.** 반드시 모니터(감사) 단계부터.

## 5. 비용

- 어플라이언스 + **단말/사용자당** 라이선스. 국산은 에이전트 추가비 없음(지니언스).
- **숨은 비용 = 802.1X 미지원 스위치 교체**(최대 변수) + 역할·정책 설계·예외 목록 운영.

## 6. 시장

- 세계 NAC 시장 **$5.43B(2025) → $48.8B(2035)**, CAGR 24.7% *(SNS Insider, 2026-07)*. 동력: IoT·BYOD·제로트러스트·규제.
- 글로벌: Cisco ISE · Aruba ClearPass · Forescout · Fortinet FortiNAC · Portnox.
- 국내: **지니언스(Genian NAC) 1위**(자사 발표) — ISMS-P·망분리 대응, 에이전트리스 중심.

## 7. 어떤 환경에 맞나

| 상황 | 권장 |
|---|---|
| 병원·공장·캠퍼스(IoT·OT 많음) | NAC 강력 추천 |
| ISMS-P·공공·금융 규제 | NAC 사실상 필수 |
| 방문자·BYOD 빈번 | 게스트 포털+격리망 |
| 원격·클라우드 앱 접근 | ZTNA (NAC로는 부족) |
| 레거시 스위치 다수 | 단계 도입·장비 계획 선행 |

## 흔한 오해와 함정

- **802.1X 바로 전면 강제** → 프린터·IoT 끊김, 모니터 단계부터
- **NAC=ZTNA 대체** → L2 vs L7, 보완 관계
- **에이전트리스면 다 된다** → 단말 내부는 에이전트 필요
- **자산 대장 없이 도입** → 정책을 못 짠다
- **예외(MAB) 목록 방치** → 곧 ‘뒷문’, 지속 관리 필수

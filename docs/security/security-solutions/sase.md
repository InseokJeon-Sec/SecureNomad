# SASE 바로 알기 — 원리부터 도입·비용·시장까지

> **대상 독자:** 솔루션을 실제로 검토·도입하는 실무 담당자. 원리도 충실히 다루되, "무엇을 준비하고 얼마가 들며 무엇을 고를까"에 무게를 둡니다.
> **숫자 표기 원칙:** 시장·가격 수치는 변동이 크므로 모두 **출처와 기준 시점**을 함께 적었습니다. 계약 견적이 아닌 참고용 범위입니다.
> **먼저 읽으면 좋은 글:** [ZTNA 바로 알기](./ztna.md) — SASE의 핵심 구성요소가 ZTNA입니다.

## 1. SASE란 무엇인가 — 그리고 왜 생겼나

**SASE(Secure Access Service Edge, '새시'로 읽음)**는 흩어져 있던 **네트워크(WAN)와 보안 기능을 하나의 클라우드 서비스로 융합**한 아키텍처입니다. 가트너가 2019년 제시한 개념으로, 핵심은 "**사용자·기기가 어디에 있든, 가까운 클라우드 접점(PoP)에서 연결과 보안을 동시에 처리한다**"는 것입니다.

SASE는 제품 하나가 아니라 **다섯 구성요소의 묶음**입니다.

| 구성요소 | 역할 | 비고 |
|---|---|---|
| **ZTNA** | 앱 단위 제로트러스트 접근 | VPN 대체 ([별도 문서](./ztna.md)) |
| **SWG** (Secure Web Gateway) | 웹 트래픽 필터링·악성 차단 | 프록시 |
| **CASB** (Cloud Access Security Broker) | SaaS 가시성·통제·DLP | 섀도 IT 통제 |
| **FWaaS** (Firewall as a Service) | 클라우드 방화벽 | 포트·프로토콜 |
| **SD-WAN** | 지점·회선 최적 경로 | 네트워크(WAN) 축 |

> **SSE vs SASE:** 위에서 **보안 4종(ZTNA+SWG+CASB+FWaaS)만 묶은 것이 SSE**(Security Service Edge), 여기에 **SD-WAN(네트워크)까지 더한 것이 SASE**입니다. 그래서 가트너의 **SSE 매직 쿼드런트**가 사실상 SASE 보안 역량의 바로미터입니다.

### 왜 SASE로 가나

- **경계의 소멸** — 원격·하이브리드·멀티클라우드로 "본사 게이트웨이로 백홀"하는 모델이 깨짐.
- **포인트 제품의 피로** — VPN·프록시·방화벽·CASB를 **따로따로** 사면 정책 중복, 로그 분산, 운영 과부하.
- **성능** — 전 세계 PoP에서 가까이 처리해 지연을 줄임.
- **일관된 정책** — "누가·무엇을·어디서"를 **한 콘솔**에서.

## 2. 동작 원리와 아키텍처

```text
[지점/원격 사용자/기기]                [SASE 클라우드 (전 세계 PoP)]            [목적지]
  본사 · 지점 · 재택 · 모바일              ┌─────────────────────────────┐          인터넷/SaaS
        │                                   │  ZTNA · SWG · CASB · FWaaS   │          내부 앱(IaaS/DC)
        │ ─── 가까운 PoP로 연결 ──────────▶ │  (한 번 검사로 정책 일괄 적용)│ ───────▶
        │   (SD-WAN/에이전트/터널)          │  신원·기기·맥락 기반 평가     │
        │ ◀──────────────────────────────── │  로그·가시성 단일화          │
                                            └─────────────────────────────┘
```

핵심 아이디어는 **"single-pass 검사"** — 트래픽이 한 번 PoP를 지날 때 ZTNA·SWG·CASB·방화벽 정책을 **한꺼번에** 적용합니다. 포인트 제품을 체이닝하며 여러 번 검사하던 구조를 없앱니다.

### 단일벤더 SASE vs 통합(2-벤더) SASE

| 구분 | 단일벤더 SASE | 통합(dual-vendor) SASE |
|---|---|---|
| 방식 | 보안+네트워크를 한 벤더로 | 보안(SSE) + 네트워크(SD-WAN)를 각각 강자로 |
| 장점 | 정책·콘솔·로그 일원화, 운영 단순 | 각 영역 최강 조합, 기존 SD-WAN 재활용 |
| 한계 | 특정 영역이 약할 수 있음, 종속(lock-in) | 연동·정책 경계 복잡 |
| 적합 | 신규·단순화 지향 | 이미 SD-WAN 투자/네트워크팀 강한 조직 |

## 3. 도입 실무 준비 — 회사가 무엇을 알아야 하나

SASE는 보안과 네트워크를 **동시에** 건드리므로, ZTNA보다 조사 범위가 넓습니다. **① 파악, ② 생성·준비, ③ 결정** 순으로.

### 3-1. 먼저 '파악'해야 할 것 (현황 조사)

| 대상 | 구체적으로 알아야 하는 것 |
|---|---|
| **현재 보안 스택** | 지금 쓰는 VPN·SWG·방화벽·CASB·프록시가 **각각 무엇이고 계약 만료일**이 언제인지 (전환 타이밍 핵심) |
| **지점·회선** | 사업장 수, 각 지점 **회선 종류·대역폭**, SD-WAN/라우터 장비 현황 |
| **트래픽 패턴** | 인터넷 vs 내부 앱 vs SaaS 비율, 지연 민감 트래픽(화상·VoIP) |
| **SaaS 목록** | CASB로 통제할 **승인/비승인 SaaS**(섀도 IT) 현황 |
| **사용자·기기** | 관리/비관리 단말 OS·수량, 지점/원격/모바일 분포 |
| **규제·망분리** | 공공·금융의 망분리·N2SF·데이터 소재지 요구 |

### 3-2. 미리 '생성·준비'해야 할 것

- **IdP·MFA 선결** — ZTNA와 동일. 모든 접근 판단의 뿌리.
- **PoP 위치 확인** — 벤더가 **국내(또는 가까운) PoP**를 두는지. SASE는 트래픽을 PoP로 보내므로 **PoP가 멀면 지연**이 생깁니다. (국내 실무의 핵심 점검 항목)
- **SD-WAN 엣지 장비** — 지점별 엣지(물리/가상) 수급·설치 계획.
- **SSL 인스펙션용 루트 CA 배포** — 전수 검사를 하려면 단말에 검사용 인증서 배포 필요(배포 수단·예외 도메인 목록).
- **커넥터/터널·서비스 계정** — 내부 앱 연동용 커넥터와 전용 계정(ZTNA와 동일 개념).
- **에이전트 배포 체계** — MDM/Intune/GPO로 단말 에이전트 배포, 비관리는 클라이언트리스.
- **로그·SIEM 연동** — 단일 콘솔 로그를 SOC로.

### 3-3. '결정'해야 할 정책·전략

- **단일벤더 vs 통합** — 위 2장의 트레이드오프로 선택.
- **도입 순서** — 보통 **ZTNA/SWG부터 → CASB·DLP → SD-WAN** 순으로 단계 전환(한 번에 다 바꾸지 않음).
- **SSL 전수검사 범위** — 성능·프라이버시·앱 호환성(인증서 피닝 앱 예외) 고려.
- **지점 전환 순서·병행 기간** — 파일럿 지점 → 확산, 기존 회선·장비와 공존 기간.
- **네트워크팀 ↔ 보안팀 거버넌스** — SASE는 두 조직의 소유가 겹치므로 **역할·책임(RACI)**을 먼저 합의.

> **요약:** SASE 도입의 절반은 "지금 뭘 쓰고 있고(계약 만료 포함), 지점·회선·SaaS가 어떤 모습인가"를 숫자로 그리는 일입니다.

## 4. 비용 구조

### 과금 모델

주로 **사용자당 구독(월/년)**이며, 지점 단위·대역폭(Mbps/Gbps) 과금이 섞입니다. 구성요소를 **모듈(SKU)별**로 파니, 필요한 것만 고르되 핵심 기능이 상위 번들에 있는지 확인해야 합니다.

### 참고 가격 (per user·월, 근사치 · 변동 큼)

| 벤더/범주 | 참고가(월) | 비고 |
|---|---|---|
| Cloudflare One | **US$7~12** | 경량·클라우드 네이티브 |
| Zscaler | **US$8~15** | 1,000명 구간에서 단가 하락 |
| Palo Alto Prisma Access | **US$14~22** | |
| Netskope | **US$12~18** (풀 SASE **$40~75**) | CASB는 앱-시트 과금 주의 |
| FortiSASE | **US$18~21** (실 TCO ~$33) | 지점 하드웨어·대역폭 별도 |
| Cato Networks | **US$20~50** | SD-WAN 포함형 |
| 미드마켓 풀 플랫폼 기준선 | **US$14~22** / 실 TCO **$33~60+** | |

*(출처: Jimber, SASE Pricing Models Explained, 2026-07 — 근사치)*

### 숨은 비용 (실무에서 자주 빠뜨림)

- **지점 하드웨어/SD-WAN 엣지** — 지점당 장비·설치비.
- **대역폭 초과(overage)** — 기본 제공 대역폭 초과 시 과금(예: FortiSASE 기본 1.5Mbps/user, 추가 25Mbps 블록 약 $1,100/년).
- **도입·구축(PS)** — 통합사 공수 약 **$1,200~1,800/일**, 엔터프라이즈 롤아웃 **$150,000~225,000**, 1년차 오버헤드 **+30~50%**.
- **보안 애드온** — DLP·고급 모니터링이 기본가를 배로 올리기도.
- **갱신 인상·프리미엄 지원·컴플라이언스 로그 보관**(NIS2급 180일+ 보관 약 $4,000~8,000/년).

*(출처: Jimber 2026-07, zerotrustcost.com 2026-09)*

## 5. 시장 지형 — 글로벌 vs 국내

### 시장 규모·점유율

- **SASE 시장:** 2024년 3분기 분기 매출 **약 US$24억**. **상위 6사(Zscaler·Cisco·Palo Alto·Broadcom·Fortinet·Netskope)가 72%**를 점유(1년 새 +7%p). **Zscaler가 21%로 전체 1위**, SSE 부문에선 **34%**. SD-WAN 부문은 **Cisco 31%**. 성장은 **SSE +14%, SD-WAN +1%** (YoY). *(Dell'Oro Group, 2024년 3분기 보고서 — IT-Online 2025-01-03 보도)*

### 글로벌 벤더 지형 (Gartner SSE 2025)

- **Gartner SSE 매직 쿼드런트 2025(2025-05-20) 리더:** **Netskope · Palo Alto Networks · Zscaler** (Palo Alto는 3년 연속 리더)
- **챌린저:** Fortinet / **니치:** Versa · Broadcom · Cloudflare · iboss · Skyhigh
- SD-WAN까지 묶은 **단일벤더 SASE**로는 **Cato Networks, Fortinet, Palo Alto, Cisco**가 자주 거론.

### 국내 지형 (글로벌과 다른 점)

- **구조 차이:** 글로벌은 **단일벤더 SASE 플랫폼으로 재편**되는 반면, **국내는 ZTNA를 시작으로 SWG·CASB·DLP를 점차 연계**하는 방식. 완성형 SASE보다 **구성요소 단계 도입**이 현실적.
- **PoP·지연:** 글로벌 SASE는 국내 PoP 유무가 체감 성능을 좌우 → 국내 도입 시 **반드시 확인**.
- **국산 진영:** 안랩·퓨쳐시스템·모니터랩·소프트캠프·이니텍 등이 **ZTNA/SSE 요소**를 제공하며 SASE 방향으로 확장 중(완전한 글로벌형 단일벤더 SASE는 제한적). *(보안뉴스 2026-10-27)*
- **규제·공공:** 국내는 법적 의무화가 없고 **공공이 N2SF로 사실상 요구**하며 KISA 시범사업으로 마중물. (미국 EO14028, EU NIS2·DORA, 일본 의무화와 대비)

## 6. 어떤 환경에 SASE가 맞나 (의사결정 가이드)

| 상황 | 권장 |
|---|---|
| 지점 다수 + 원격 + SaaS 많음, 포인트 제품 난립 | **SASE(단일벤더)** — 통합·단순화 효과 큼 |
| 이미 SD-WAN에 투자, 네트워크팀 강함 | **통합(2-벤더) SASE** — SSE만 추가 |
| 당장은 원격 접근만 급함 | **ZTNA 먼저**, SASE는 로드맵으로 |
| SaaS 통제·DLP가 급선무 | **SSE(특히 CASB) 우선** |
| 공공·금융·망분리 환경 | 국산 + 단계 도입, **국내 PoP·망연계 정합성** 확인 |
| 소규모·단순 조직 | 경량 플랫폼(Cloudflare 등) 또는 ZTNA 단품 |

## 7. 흔한 오해와 함정

- **"SASE = 제품 하나 사면 끝"** → SASE는 **아키텍처/프레임워크**입니다. 구성요소를 단계적으로 맞춰가는 여정.
- **"단일벤더가 무조건 정답"** → 단순하지만 **특정 영역이 약하거나 종속(lock-in)** 될 수 있음. 통합형과 저울질 필요.
- **"보안팀만의 일"** → **SD-WAN(네트워크)과 보안의 소유가 겹칩니다.** 조직 간 RACI를 먼저 합의하지 않으면 운영에서 충돌.
- **"국내도 글로벌 SASE 그대로"** → **PoP·지연·망분리**가 변수. 국내 환경 적합성을 별도 검증.
- **"단가만 비교"** → 지점 하드웨어·대역폭 초과·구축·갱신까지 **TCO**로. (실 TCO가 정가의 2배 이상인 사례 흔함)
- **"SSL 전수검사 켜면 안전"** → 성능·프라이버시·인증서 피닝 앱 호환성 문제. **범위를 설계**해야 함.

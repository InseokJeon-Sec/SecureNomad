# Tencent 클라우드 바로 알기

> **대상 독자:** 솔루션을 검토·도입하는 담당자. 숫자는 **출처·기준시점**을 함께 표기합니다.

## 1. 개요 · 강점

텐센트(위챗·게임)의 클라우드, 2013년부터. 23리전·66 AZ, CDN 3,200+, 한국 지원센터. 700+ 서비스.

- **강점** — 게임·미디어(팰월드 호스팅·라이브), **WeChat 미니프로그램** 생태계, eKYC·생체, 동남아 확장.
- 범용보다 **특정 워크로드**에서 강합니다.

## 2. 시장 위치

| 벤더 | 중국 점유율(Q1 2025) |
|---|---|
| Alibaba Cloud | 33% (1위) |
| Huawei Cloud | 18% (2위) |
| **Tencent Cloud** | **10% (3위)** |

글로벌로는 약 2%(8위). 중국 내에선 **로컬 3사**가 주류 — 규제가 글로벌 3사의 진입을 제한합니다. *(출처: Canalys Q1 2025·Synergy)*

## 3. 보안 서비스 (글로벌과 대응)

| 영역 | Tencent | AWS 대응 |
|---|---|---|
| 신원·권한 | **CAM** | IAM |
| 네트워크 | Anti-DDoS · CFW | Shield · 방화벽 |
| 웹 | WAF | WAF |
| 워크로드 | **CWP** | GuardDuty/Inspector 류 |
| 키 | KMS · SSL | KMS · ACM |
| 통합 점검 | Security Center | Security Hub |

→ 구성·**공동책임 모델이 글로벌과 거의 동일**. 기술은 낯설지 않습니다.

## 4. 진짜 차이는 ‘규제’ — 중국 클라우드 고려사항

| 고려 | 내용 |
|---|---|
| **데이터 주권** | 데이터가 중국에 저장 — 소재지 이슈 |
| **중국 규제** | 사이버보안법·데이터보안법·PIPL |
| **데이터 역외 이전** | 국외 반출 제한·심사 대상 |
| **ICP 비안** | 중국 내 서비스는 등록 필수 |
| **지정학·신뢰** | 민감 데이터의 정책적 고려 |
| **국내 규제 정합** | 한국 망분리·개인정보법과 조율 |

> 핵심 질문 = **‘이 데이터를 중국에 둬도 되는가’**. 기술이 아니라 규제·주권이 결정.

## 5. 도입 실무 — 파악 · 준비 · 결정

**① 파악** — 대상 워크로드·사용자 위치, 데이터 등급·민감도, 한·중 규제 범위, **중국 본토 vs 해외 리전**(적용 법이 다름).

**② 준비** — 리전 선택·ICP 비안, CAM 최소권한·로깅, 데이터 역외이전 검토, 암호화·키관리.

**③ 결정** — 중국에 둘 데이터 범위, 분리·격리 설계, 현지 파트너·지원, 비상·종료 전략.

## 6. 어떤 환경에 쓰나

| 상황 | 권장 |
|---|---|
| 게임·미디어·라이브 | 텐센트 강점 — 적합 |
| 중국 진출·중국 사용자 | 로컬 클라우드 필요 |
| WeChat 미니프로그램 연계 | 생태계 강점 |
| 동남아 확장 | 리전·지원 활용 |
| 민감·규제 데이터(한국) | 중국 저장 신중 — 부적합할 수 |

## 흔한 오해와 함정

- **글로벌 클라우드와 똑같이 본다** → 기술은 닮아도 규제·주권 다름
- **데이터 역외 이전 간과** → 설계 단계에서 따질 것
- **ICP 비안 누락** → 중국 내 서비스 운영 불가
- **본토·해외 리전 혼동** → 리전 선택이 규제 결정
- **민감 데이터 주권 미검토** → 리스크를 사후 발견

# 보안 솔루션 바로 알기 — 개요와 지형도

> **이 시리즈의 목적:** 실제로 솔루션을 **검토·도입하는 담당자**를 위해, 각 보안 솔루션을 "원리 → 도입 준비 → 비용 → 시장 → 선택 기준" 순으로 정리합니다. 시장·가격 수치는 **출처와 기준 시점**을 함께 표기합니다.

## 왜 '지형도'부터 보나

보안 솔루션은 이름이 비슷하고 기능이 겹칩니다(ZTNA·SASE·SSE·VPN…). 그래서 개별 제품을 보기 전에 **무엇이 무엇을 포함하는지** 큰 지도를 먼저 잡는 게 빠릅니다.

### SSE / SASE / ZTNA 관계

```text
                 ┌──────────────────────── SASE ────────────────────────┐
                 │                                                        │
                 │   ┌──────────────── SSE (보안) ───────────────┐       │
                 │   │   ZTNA   ·   SWG   ·   CASB   ·   FWaaS    │  +    │  SD-WAN
                 │   │  (접근)   (웹)     (SaaS)    (방화벽)       │ (네트워크)
                 │   └───────────────────────────────────────────┘       │
                 └────────────────────────────────────────────────────────┘

· ZTNA  : 앱 단위 제로트러스트 접근 제어 (VPN 대체)
· SSE   : 보안 4종 묶음 (ZTNA + SWG + CASB + FWaaS)
· SASE  : SSE + SD-WAN(네트워크)까지 융합한 아키텍처
```

- **ZTNA**는 가장 작은 단위(접근 제어). VPN을 대체합니다.
- **SSE**는 ZTNA를 포함한 **보안 기능 묶음**.
- **SASE**는 SSE에 **네트워크(SD-WAN)**까지 더한 **가장 큰 우산**.

→ 그래서 가트너의 **SSE 매직 쿼드런트**가 사실상 SASE 보안 역량의 바로미터입니다.

## 공통 비교 프레임 (7단)

이 시리즈의 모든 솔루션 문서는 같은 틀로 작성합니다. 솔루션 간 비교가 쉬워집니다.

1. **정의 + 왜 생겼나** — 해결하려는 위협·한계
2. **동작 원리·아키텍처** — 도식 중심
3. **도입 실무 준비** — 회사가 ① 파악할 것 ② 생성·준비할 것 ③ 결정할 것
4. **비용 구조** — 과금 모델·참고가·숨은 비용
5. **시장 지형** — 글로벌 vs 국내 (출처+시점)
6. **환경별 적합도** — 의사결정 가이드
7. **흔한 오해·함정**

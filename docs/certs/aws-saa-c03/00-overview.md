## 공부 로드맵

1. **도메인별 핵심 서비스** 를 먼저 익힌다 (IAM·VPC·S3·EC2·RDS·Route 53 등).
2. 각 도메인의 **설계 선택지 비교**(언제 무엇을)를 정리한다.
3. **시나리오형 문제**에 맞춰 "요구사항 → 적합한 서비스/구성"을 연결하는 훈련.
4. 오답 노트 → 약한 도메인 반복.

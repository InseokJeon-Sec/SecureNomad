# 11. 멀티모달

**멀티모달** AI는 텍스트에 더해 이미지·음성·문서·영상 등 여러 형태(modality)를 함께 이해·생성한다.

## 가능한 작업

| 입력 | 활용 |
|---|---|
| 이미지 + 텍스트 | 스크린샷 에러 분석, 다이어그램 설명 |
| 음성 | 받아쓰기, 음성 대화 |
| 문서(PDF 등) | 요약, 표·그림 이해 |
| 이미지 생성 | 텍스트 기반 생성 |

## 원리 (고수준)

핵심은 [08. 임베딩](../using/08-embeddings.md)과 같다. 이미지·음성도 벡터로 변환해 텍스트와 **같은 공간**에서 다룬다.

```text
텍스트 →┐
이미지 →┤→ 공통 벡터 공간 → 모델이 함께 처리
음성  →┘
```

## 보안·실무 관점

- 스크린샷·로그 이미지·문서를 직접 분석할 수 있어 편리하다.
- 이미지·문서에도 민감정보가 담기므로 외부 전송 전 제거한다([12. 로컬 LLM](./12-local-llm.md)).
- 이미지 속 숨은 지시로 모델을 속이는 **멀티모달 프롬프트 인젝션** 등 새 공격면이 생긴다.

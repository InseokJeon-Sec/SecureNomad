# 12. 로컬 LLM

**로컬 LLM**은 외부 서비스가 아니라 내 PC·사내 서버에서 직접 실행하는 모델이다.

## 클라우드 vs 로컬

클라우드 LLM은 입력을 외부로 전송하지만, 로컬 LLM은 데이터가 환경을 벗어나지 않는다.

| | 클라우드 LLM | 로컬 LLM |
|---|---|---|
| 데이터 전송 | 외부 제공자로 전송 | 내 환경 내 |
| 성능 | 최상위 모델 가능 | 하드웨어에 제한 |
| 비용 | 사용량 과금 | 초기 하드웨어, 이후 무료 |
| 오프라인 | 불가 | 가능 |
| 관리 | 제공자 운영 | 직접 설치·운영 |

이 "데이터 비유출" 특성이 [AI 보안 도구](/security/ai-for-security/ai-tools/overview)의 데이터 처리 축에서 로컬을 높게 치는 근거다.

## 실행 (개념)

Ollama 등 실행기로 오픈소스 모델(Llama·Mistral·Qwen 등)을 받아 로컬에서 추론한다. GPU가 있으면 빠르고, 없으면 작은 모델은 CPU로도 가능하다.

## 한계

- 최상위 성능은 아직 클라우드 모델이 우세한 경우가 많다.
- 큰 모델은 고사양 하드웨어(특히 GPU 메모리)를 요구한다.
- 설치·업데이트·보안 관리를 직접 해야 한다.

민감 데이터는 로컬, 일반 작업은 클라우드로 분리하는 전략이 현실적이다.

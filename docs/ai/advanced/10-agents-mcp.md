# 10. AI 에이전트 · 툴 · MCP

기본 LLM은 질문에 답하는 수동적 모델이다. 여기에 도구를 부여해 스스로 작업을 수행하게 한 것이 **AI 에이전트**다.

## 툴 (함수 호출)

기본 LLM은 텍스트만 생성하고 계산·검색·파일 접근 같은 실제 행동은 하지 못한다. **툴/함수 호출(function calling)** 은 LLM이 필요 시 미리 연결된 함수를 호출하게 한다.

```text
"오늘 서울 날씨?"  →  LLM이 get_weather("서울") 호출  →  결과(맑음, 20도) 수신  →  답변 생성
```

이로써 LLM이 실시간 정보·외부 시스템과 연결된다. 무엇을 호출할지는 LLM이 판단하므로 오호출·오남용 가능성이 있다.

## 에이전트

**에이전트**는 목표를 받아 **계획 → 도구 사용 → 결과 판단 → 반복**을 스스로 수행한다. 보안 분야의 자동 침투 테스트 도구([ARTEX·PentestGPT](/security/ai-for-security/ai-tools/overview))가 그 예다.

:::warning 에이전트 보안 위험
스스로 도구를 쓰는 만큼 잘못된 행동·과도한 권한·프롬프트 인젝션에 취약하다. 권한을 최소화하고 위험한 행동은 사람 확인을 거치게 설계한다.
:::

## MCP

**MCP(Model Context Protocol)** 는 AI와 외부 도구·데이터를 연결하는 표준 규약이다. 도구마다 제각각이던 연결 방식을 공통 규격으로 통일해, 한 번 만든 도구(MCP 서버)를 여러 AI에서 재사용한다.

```text
[AI 앱] ──MCP── [파일 서버] · [DB 서버] · [사내 시스템]
```

툴·에이전트·MCP는 강력한 만큼 권한·보안 설계가 함께 가야 한다.

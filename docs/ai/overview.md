# AI 기초

요즘 가장 뜨거운 주제인 **AI(특히 LLM, 대규모 언어 모델)** 를 개념부터 차근차근 정리합니다.
수식 없이, IT·보안 배경이 있는 사람이 "원리를 이해하는" 데 초점을 둡니다.

:::tip 이 섹션의 성격
- **AI 기초(여기)**: AI *기술 자체*를 이해 — LLM이 뭔지, 어떻게 동작하는지
- **[AI for Security](/security/ai-for-security/overview)**: AI를 *보안에* 활용하는 쪽
:::

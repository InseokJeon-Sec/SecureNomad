# 09. 파인튜닝 vs RAG vs 프롬프트

AI를 원하는 대로 동작시키는 방법은 세 가지이며, 경쟁이 아니라 용도가 다르다.

| | 프롬프트 | RAG | 파인튜닝 |
|---|---|---|---|
| 방식 | 지시·맥락을 입력 | 외부 자료를 검색·결합 | 모델을 추가 학습 |
| 적합 | 형식·말투·간단한 맥락 | 최신·내부 지식 | 특정 말투·형식·전문성 체화 |
| 비용·난이도 | 낮음 | 중간(파이프라인) | 높음(데이터·학습) |
| 지식 갱신 | 매번 입력 | 저장소 갱신 | 재학습 |

## 선택 기준

| 목표 | 선택 |
|---|---|
| 답 형식·말투 조정 | 프롬프트 |
| 내부 문서·최신 정보 반영 | RAG |
| 특정 도메인 판단·말투 체화 | 파인튜닝 |
| 정확한 사실 + 특화 스타일 | RAG + 파인튜닝 |

판단 순서: **프롬프트로 해결 → 지식 부족이면 RAG → 스타일·전문성 필요하면 파인튜닝.** 지식 주입은 파인튜닝보다 RAG가 저렴·유연하며, 파인튜닝은 환각을 줄일 수는 있어도 근본 해결책은 아니다(사실 근거는 RAG가 담당).

# 06. 프롬프트 기초

**프롬프트**는 LLM에 주는 입력 전체(지시·맥락·질문)다.

## 핵심 개념

| 개념 | 정의 |
|---|---|
| 프롬프트 | 모델에 주는 입력 전체 |
| 컨텍스트 윈도 | 한 번에 처리 가능한 토큰 수 한계(입력+출력 합산) |
| 토큰 | 처리 단위([03](../foundations/03-how-llm-works.md)), 비용·한도 기준 |

컨텍스트 윈도를 초과하면 앞부분이 유실된다. 긴 문서는 요약·부분 발췌·[RAG](./07-rag.md)로 처리한다.

## 작성 원칙

| 원칙 | 나쁜 예 | 좋은 예 |
|---|---|---|
| 구체성 | "보안 알려줘" | "OWASP Top 10을 항목당 2줄로 설명" |
| 역할·맥락 | "검토해줘" | "보안 검토자로서 아래 코드 취약점을 심각도순으로" |
| 형식 지정 | "비교해줘" | "표로, 열은 도구·장점·단점" |
| 예시 제공 | — | "이 형식으로: [예시1][예시2]" |
| 단계 유도 | "답만" | "근거와 함께 단계적으로" |

## 보안 주의

:::warning 프롬프트에 민감정보 금지
클라우드 LLM 입력은 외부로 전송된다. 실제 계정·키·내부 코드·개인정보를 그대로 넣지 않는다. 필요 시 익명화하거나 [로컬 LLM](../advanced/12-local-llm.md)을 쓴다.
:::

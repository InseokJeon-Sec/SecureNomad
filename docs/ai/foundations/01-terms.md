# 01. 용어 정리

뉴스에서 AI, 머신러닝, 딥러닝, 생성형 AI, LLM이 뒤섞여 쓰인다. 이 용어들은 **포함 관계**다.

```text
AI (인공지능)  ── 사람의 지능을 흉내 내는 모든 기술
 └ 머신러닝    ── 데이터로 스스로 규칙을 "학습"하는 AI
    └ 딥러닝    ── 인공신경망을 깊게 쌓아 학습하는 머신러닝
       └ 생성형 AI ── 새 콘텐츠(글·이미지 등)를 만들어내는 딥러닝
          └ LLM   ── 그중 '언어'를 다루는 대규모 모델 (예: GPT, Claude)
```

## 하나씩

| 용어 | 뜻 | 예시 |
|---|---|---|
| **AI (인공지능)** | 사람의 지능적 행동을 흉내 내는 기술 전체 | 체스 프로그램, 추천 알고리즘 |
| **머신러닝 (ML)** | 사람이 규칙을 일일이 짜지 않고, **데이터로 규칙을 학습** | 스팸 메일 분류, 수요 예측 |
| **딥러닝 (DL)** | 뇌의 뉴런을 본뜬 **인공신경망**을 깊게 쌓아 학습 | 이미지 인식, 음성 인식 |
| **생성형 AI** | 분류·예측을 넘어 **새 콘텐츠를 생성** | 글쓰기, 그림 생성 |
| **LLM** | 생성형 AI 중 **언어**를 다루는 초대형 모델 | ChatGPT, Claude, Gemini |

## 규칙 기반 vs 머신러닝 (핵심 차이)

예전 방식과 머신러닝의 가장 큰 차이는 **"규칙을 누가 만드느냐"** 다.

| | 규칙 기반 (전통) | 머신러닝 |
|---|---|---|
| 규칙 | 사람이 직접 코딩 | 데이터에서 자동으로 학습 |
| 스팸 판별 예 | "제목에 '광고' 있으면 스팸" 같은 규칙을 사람이 작성 | 스팸/정상 메일 수만 건을 보여주고 패턴을 스스로 터득 |
| 한계 | 경우의 수가 많으면 규칙이 폭발 | 데이터만 있으면 복잡한 패턴도 학습 |

보안으로 비유하면, 규칙 기반은 **시그니처 탐지**(알려진 패턴), 머신러닝은 **이상 탐지**(데이터로 정상/비정상 학습)에 가깝다.

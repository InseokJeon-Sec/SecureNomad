# 01. 용어 정리

이 문서의 내용은 영상으로도 볼 수 있다.

<YouTube id="FTbxcQ0UpPI" title="AI·머신러닝·딥러닝·생성형 AI·LLM 차이 한 번에 정리 (보안 관점) | AI 바로 알기 #1" />

AI·머신러닝·딥러닝·생성형 AI·LLM은 **포함 관계**다.

```text
AI (인공지능)  ── 사람의 지능을 흉내 내는 모든 기술
 └ 머신러닝    ── 데이터로 규칙을 학습하는 AI
    └ 딥러닝    ── 인공신경망을 깊게 쌓아 학습하는 머신러닝
       └ 생성형 AI ── 새 콘텐츠를 생성하는 딥러닝
          └ LLM   ── 그중 언어를 다루는 대규모 모델 (GPT, Claude 등)
```

| 용어 | 정의 | 예 |
|---|---|---|
| **AI** | 지능적 행동을 흉내 내는 기술 전반 | 체스 엔진, 추천 알고리즘 |
| **머신러닝(ML)** | 규칙을 코딩하지 않고 데이터로 학습 | 스팸 분류, 수요 예측 |
| **딥러닝(DL)** | 인공신경망 기반 학습 | 이미지·음성 인식 |
| **생성형 AI** | 분류·예측을 넘어 콘텐츠 생성 | 텍스트·이미지 생성 |
| **LLM** | 언어를 다루는 대규모 생성 모델 | ChatGPT, Claude, Gemini |

## 규칙 기반 vs 머신러닝

핵심 차이는 **규칙을 사람이 만드느냐, 데이터에서 학습하느냐**다.

| | 규칙 기반 | 머신러닝 |
|---|---|---|
| 규칙 | 사람이 코딩 | 데이터에서 학습 |
| 스팸 판별 | "제목에 '광고' 포함 시 스팸" 식 규칙 작성 | 다량의 스팸/정상 메일에서 패턴 학습 |
| 한계 | 경우의 수가 많으면 규칙 폭발 | 데이터만 있으면 복잡한 패턴도 학습 |

보안에 대응하면 규칙 기반은 **시그니처 탐지**, 머신러닝은 **이상 탐지**에 해당한다.

## 보안 관점

각 계층은 보안에서 서로 다른 의미를 가진다. 포함 관계를 위협과 함께 보면 다음과 같다.

| 계층 | 보안에서의 의미 | 대표 위협 |
|---|---|---|
| 머신러닝 | 탐지를 규칙에서 학습 기반으로 넓힌다 | 적대적 입력으로 분류기 회피, 오탐·미탐 |
| 딥러닝 | 모델 자체가 공격 대상이 된다 | 적대적 예제, 모델 추출, 백도어 |
| 생성형 AI | 콘텐츠를 만들어내는 능력이 악용된다 | 딥페이크, 피싱·사회공학 자동화 |
| LLM | 외부 입력이 곧 실행 맥락이 된다 | 프롬프트 인젝션, 민감정보 유출, 과도한 권한 |

보안에서 AI는 세 갈래로 나눠 보면 정리된다.

- **AI for Security** — AI를 방어·진단의 도구로 쓴다. → [AI for Security](/security/ai-for-security/overview)
- **Securing AI** — AI 사용 자체를 안전하게 만든다(위협 모델·평가·가이드). → [Securing AI](/security/ai-security-assessment/overview)
- **AI as Threat** — 공격자가 AI를 악용한다(자율 침투, 공격 자동화).

같은 기술을 공격·방어·보호 중 어느 쪽에서 보느냐의 차이이고, 세 관점은 서로 맞물린다.

## 정리

- 포함 관계: **AI ⊃ 머신러닝 ⊃ 딥러닝 ⊃ 생성형 AI ⊃ LLM**
- 통상 "AI"는 생성형 AI·LLM을 가리킨다.
- 보안에서는 이 구분이 **위협의 종류와 대응 지점**을 가른다. 계층이 내려갈수록 공격면이 외부 입력(프롬프트)과 실행 권한 쪽으로 옮겨 간다.

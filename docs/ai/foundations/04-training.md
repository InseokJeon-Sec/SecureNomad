# 04. 어떻게 학습되나

LLM은 보통 **3단계**로 완성된다.

![LLM 학습 3단계 — 사전학습 · 파인튜닝 · RLHF](/img/ai/training-ko.svg)

## 1. 사전학습

방대한 텍스트로 다음 토큰 예측을 반복 학습하며 문법·상식·세계 지식·추론의 토대를 형성한다. 가장 비싸고 오래 걸리는 단계다. 이 단계의 산출물은 지식은 많지만 지시 수행에는 미숙해, 답변보다 텍스트 연장에 치우친다.

## 2. 파인튜닝

사전학습 모델을 특정 용도·형식에 맞게 추가 학습한다. 대표적으로 **지시 튜닝(instruction tuning)** 으로 질문에 답하고 요청 형식을 따르는 방식을 익힌다. 기업이 자사 데이터로 용도 특화 모델을 만들 때도 쓰인다([09. 파인튜닝 vs RAG](../using/09-finetune-vs-rag.md)).

## 3. RLHF (사람 피드백 기반 강화학습)

모델이 낸 여러 답을 사람이 선호로 평가하고 그 선호를 반영한다. 도움·안전·공손함이 이 단계에서 조정된다.

:::info 제품마다 '태도'가 다른 이유
사전학습 토대가 비슷해도 파인튜닝·RLHF에서 무엇을 선호하도록 조정했는지가 달라, 말투·거절 기준·안전성이 제품별로 다르다.
:::

## 함의

- **지식 시점이 고정**된다. 수집 시점 이후는 알지 못하므로 [07. RAG](../using/07-rag.md)·검색으로 보완한다.
- **입력 데이터가 학습에 쓰일 수 있다.** 입력의 학습·보관 여부는 제품 정책마다 다르므로 보안·프라이버시 관점에서 확인한다([12. 로컬 LLM](../advanced/12-local-llm.md)).

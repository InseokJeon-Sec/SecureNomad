# 05. 환각과 한계

LLM은 그럴듯하지만 틀린 내용을 확신 있게 생성한다. 이를 **환각(hallucination)** 이라 한다. 버그가 아니라 "조회가 아닌 생성"이라는 동작 원리에서 비롯되는 특성이다([02](./02-what-is-llm.md)).

## 원인

- 모르는 것도 빈칸을 자연스럽게 메우려 한다. "모른다"보다 "그럴듯한 말"의 확률이 높게 학습될 수 있기 때문이다.
- 존재하지 않는 논문·판례·함수·URL을 형식만 맞게 생성한다.
- 확신과 정확도는 무관하다. 단정적 말투여도 틀릴 수 있다.

## 위험이 큰 상황

| 상황 | 위험 |
|---|---|
| 최신 사건 | 학습 이후라 모름 → 생성 |
| 구체적 수치·날짜·인용 | 조작되기 쉬움 |
| 전문·법률·의료 | 오류 시 피해 큼 |
| 존재 여부 질문 | 없는 것을 있다고 생성 |

## 완화

| 방법 | 설명 |
|---|---|
| 근거 제공(RAG) | 신뢰 자료 범위 내에서 답하게 함 ([07](../using/07-rag.md)) |
| 출처 요구 | 출처 명시·모르면 모른다고 지시 |
| 사람 검증 | 수치·인용·코드는 직접 확인. AI 출력은 초안으로 취급 |
| 낮은 temperature | 사실형 작업은 보수적으로 |
| 교차 확인 | 중요한 내용은 다른 출처로 재확인 |

## 그 밖의 한계

- **최신성**: 학습 시점 이후 미반영
- **일관성**: 동일 질문에 매번 다른 답
- **컨텍스트 한계**: 한 번에 처리 가능한 분량 제한
- **편향**: 학습 데이터의 편향 반영 가능

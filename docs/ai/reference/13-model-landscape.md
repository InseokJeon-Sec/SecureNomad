# 13. 모델·제공자 지형

LLM은 **클로즈드(상용 API)** 와 **오픈(가중치 공개)** 으로 나뉜다.

| 구분 | 특징 | 예 |
|---|---|---|
| 클로즈드 | API 사용, 최상위 성능, 가중치 비공개 | OpenAI(GPT), Anthropic(Claude), Google(Gemini) |
| 오픈 | 받아서 직접 실행·커스터마이즈 | Meta(Llama), Mistral, Alibaba(Qwen) |

'오픈'은 주로 가중치가 공개되어 내려받아 쓸 수 있다는 의미다. 라이선스 조건은 모델마다 다르므로 상업적 사용 전 확인한다.

## 선택 기준

| 기준 | 확인 |
|---|---|
| 성능 | 작업(코딩·추론·한국어 등)에 충분한가 |
| 데이터 처리 | 입력이 외부로 가는가 → 민감하면 오픈/로컬([12](../advanced/12-local-llm.md)) |
| 비용 | 사용량 과금 vs 자체 운영 |
| 컨텍스트 윈도 | 한 번에 넣을 수 있는 분량 |
| 라이선스 | 상업적 사용·재배포 조건 |

모델 순위·가격은 수시로 바뀌므로 특정 시점 1등보다 작업·제약에 맞는 모델을 선택하는 것이 중요하다. 민감 작업은 로컬 오픈 모델, 일반 작업은 클라우드로 나누는 혼합 전략이 흔하다.

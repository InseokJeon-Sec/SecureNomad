# 13. 모델·제공자 지형

LLM은 크게 **클로즈드(상용 API)** 와 **오픈(가중치 공개)** 모델로 나뉜다.

## 두 갈래

| 구분 | 특징 | 대표 예 |
|---|---|---|
| **클로즈드(상용)** | API로 사용, 최상위 성능, 가중치 비공개 | OpenAI(GPT), Anthropic(Claude), Google(Gemini) |
| **오픈(가중치 공개)** | 받아서 직접 실행 가능, 로컬·커스터마이즈 용이 | Meta(Llama), Mistral, Alibaba(Qwen) 등 |

:::info "오픈소스 모델"의 의미
여기서 '오픈'은 주로 **모델 가중치가 공개**되어 받아 쓸 수 있다는 뜻이다. 라이선스 조건은 모델마다 다르니 상업적 사용 전 확인이 필요하다.
:::

## 선택할 때 보는 기준

| 기준 | 질문 |
|---|---|
| **성능** | 이 작업에 충분한가 (코딩·추론·한국어 등 작업별로 다름) |
| **데이터 처리** | 입력이 외부로 가는가 → 민감하면 오픈/로컬 ([12 참고](../advanced/12-local-llm.md)) |
| **비용** | 사용량 과금 vs 자체 운영 |
| **컨텍스트 윈도** | 한 번에 넣을 수 있는 분량 |
| **라이선스** | 상업적 사용·재배포 조건 |

## 흐름

- 모델 경쟁이 빠르게 진행되어 **순위·가격은 수시로 바뀐다.** 특정 시점의 1등에 매이기보다, **"내 작업·제약에 맞는 모델"** 을 그때그때 고르는 감각이 중요하다.
- 오픈 모델의 성능이 빠르게 올라오면서, **민감 작업은 로컬 오픈 모델 + 일반 작업은 클라우드** 같은 혼합 전략이 흔해지고 있다.

## 정리

- 클로즈드(성능·편의) ↔ 오픈(프라이버시·자유도)의 트레이드오프
- **데이터 민감도 + 작업 성격 + 비용**으로 고른다.
- 최신 비교는 항상 바뀌므로, 이 문서는 "큰 그림"으로만 본다.

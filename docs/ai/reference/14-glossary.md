# 14. 용어 사전

| 용어 | 정의 |
|---|---|
| **LLM** | 대규모 언어 모델. 다음 토큰을 예측해 텍스트 생성 ([02](../foundations/02-what-is-llm.md)) |
| **토큰** | 모델의 텍스트 처리 단위(대략 단어/단어 일부). 비용·길이 기준 |
| **파라미터** | 학습으로 조정되는 가중치. 지식·패턴 저장 용량 |
| **컨텍스트 윈도** | 한 번에 처리 가능한 토큰 수 한계(입력+출력) |
| **프롬프트** | 모델에 주는 입력 전체 |
| **temperature** | 출력의 무작위성 조절값. 높으면 다양, 낮으면 보수적 |
| **사전학습** | 방대한 텍스트로 기본 능력을 학습하는 1단계 |
| **파인튜닝** | 특정 용도·형식에 맞춘 추가 학습 |
| **RLHF** | 사람 피드백으로 선호 답을 하도록 조정 |
| **환각** | 그럴듯하나 틀린 내용 생성 ([05](../foundations/05-hallucination.md)) |
| **임베딩** | 의미를 벡터로 변환 ([08](../using/08-embeddings.md)) |
| **벡터 DB** | 벡터 저장·유사도 검색 DB |
| **RAG** | 외부 근거를 검색·결합해 답하는 방식 ([07](../using/07-rag.md)) |
| **트랜스포머** | 현대 LLM의 기반 신경망 구조 |
| **어텐션** | 문맥에서 중요한 부분에 가중치를 두는 트랜스포머 핵심 |
| **툴/함수 호출** | LLM이 외부 함수를 호출해 행동하게 하는 기능 ([10](../advanced/10-agents-mcp.md)) |
| **에이전트** | 계획·도구 사용·반복으로 목표를 수행하는 AI |
| **MCP** | AI와 도구를 연결하는 표준 규약 |
| **멀티모달** | 텍스트+이미지·음성·문서를 함께 처리 ([11](../advanced/11-multimodal.md)) |
| **로컬 LLM** | 내 환경에서 직접 실행하는 모델 ([12](../advanced/12-local-llm.md)) |
| **오픈 모델** | 가중치가 공개된 모델 |
| **프롬프트 인젝션** | 악의적 입력으로 모델 지시를 가로채는 공격 |

# 14. 용어 사전

AI·LLM 문서에서 자주 나오는 용어를 한 장에 모았다.

| 용어 | 뜻 |
|---|---|
| **LLM** | 대규모 언어 모델. 다음 토큰을 예측해 글을 생성 ([02](../foundations/02-what-is-llm.md)) |
| **토큰(Token)** | 모델이 글을 다루는 조각 단위(대략 단어/단어 일부). 비용·길이 기준 |
| **파라미터(Parameter)** | 모델이 학습으로 조정하는 가중치. 지식·패턴이 담기는 그릇 |
| **컨텍스트 윈도** | 모델이 한 번에 볼 수 있는 토큰 수 한계(입력+출력) |
| **프롬프트(Prompt)** | 모델에게 주는 입력 전체(지시+맥락+질문) |
| **temperature** | 답의 무작위성/창의성 조절값. 높으면 다양, 낮으면 보수적 |
| **사전학습(Pre-training)** | 방대한 텍스트로 기본 능력을 학습하는 1단계 |
| **파인튜닝(Fine-tuning)** | 특정 용도·형식에 맞게 추가 학습 |
| **RLHF** | 사람 피드백으로 선호되는 답을 하도록 조정 |
| **환각(Hallucination)** | 그럴듯하지만 틀린 내용을 생성하는 현상 ([05](../foundations/05-hallucination.md)) |
| **임베딩(Embedding)** | 의미를 숫자 벡터로 변환 ([08](../using/08-embeddings.md)) |
| **벡터 DB** | 벡터를 저장하고 유사한 것을 빠르게 검색하는 DB |
| **RAG** | 관련 자료를 찾아 근거로 붙여 답하게 하는 방식 ([07](../using/07-rag.md)) |
| **트랜스포머(Transformer)** | 현대 LLM의 기반 신경망 구조 |
| **어텐션(Attention)** | 문맥에서 중요한 부분에 '주목'하는 트랜스포머의 핵심 장치 |
| **툴/함수 호출** | LLM이 외부 함수를 호출해 행동하게 하는 기능 ([10](../advanced/10-agents-mcp.md)) |
| **에이전트(Agent)** | 스스로 계획·도구 사용·반복하며 목표를 수행하는 AI |
| **MCP** | AI와 도구를 연결하는 표준 규약(Model Context Protocol) |
| **멀티모달** | 텍스트+이미지·음성·문서 등 여러 형태를 함께 처리 ([11](../advanced/11-multimodal.md)) |
| **로컬 LLM** | 내 PC·서버에서 직접 실행하는 모델. 데이터 외부 전송 없음 ([12](../advanced/12-local-llm.md)) |
| **오픈 모델** | 가중치가 공개되어 받아 쓸 수 있는 모델 |
| **프롬프트 인젝션** | 악의적 입력으로 모델의 지시를 가로채는 공격 |

> 더 다룰 용어가 생기면 여기에 추가한다.

# 사전학습과 사후학습 — 정렬 (기술 심화)

:::note 전제

:::

## 1. 모델은 두 단계로 완성된다

LLM은 크게 두 단계를 거쳐 만들어집니다. 앞 단계가 **능력**을, 뒤 단계가 **행동**을 결정합니다.

```text
[1단계] 사전학습(pre-training)      [2단계] 사후학습(post-training) = 정렬
방대한 원시 텍스트, 수조 토큰    →   SFT + RLHF로 행동을 다듬음
→ 베이스 모델(지식·추론 능력)        → 쓸모 있고 안전한 모델

'아는 것' = 앞 단계          '어떻게 행동할지' = 뒷 단계
```

핵심 분리: **지식·추론 능력은 사전학습에서, 지시 준수·거부 같은 행동은 사후학습(정렬)에서** 정해집니다. 그리고 보안이 걸리는 쪽은 대부분 뒤, 정렬입니다.

## 2. 1단계 — 사전학습 (다음 토큰 예측)

방식 자체는 단순합니다. `고양이가 지붕 위에` 다음에 올 토큰을 맞히는 **다음 토큰 예측(next-token prediction)** 을 수조 번 반복합니다.

```text
입력: "고양이가 지붕 위에"  →  예측: "앉아" / "올라" / ...
         (정답 토큰과의 오차로 가중치 갱신, 수조 회 반복)
```

이 과정에서 모델은 문법과 세상 지식, 추론 **능력**을 얻습니다. 다만 이 단계만 거친 베이스 모델은 **무엇을 해야 할지**는 모릅니다. 지시를 따르거나 위험한 요청을 거부하는 능력은 아직 없습니다. 능력은 거대하지만 길들여지지 않은 상태라, 그대로는 서비스에 쓸 수 없습니다.

## 3. 2단계 ① — 지도 미세조정 (SFT)

사후학습의 첫 단계는 **지도 미세조정(Supervised Fine-Tuning, SFT)** 입니다. 사람이 만든 `질문-모범 답변` 쌍 수만 개를 보여주며, 모델에게 **어떻게 응답해야 하는지**를 직접 가르칩니다.

- 이메일을 정중하게 고쳐 달라면 → 공손한 어투로
- 코드를 짜 달라면 → 코드와 설명을

이 단계에서 모델은 지시를 따르고, 형식과 말투를 맞추고, 도움이 되는 답을 내는 법을 익힙니다. 능력에 **행동의 틀**이 입혀지는 단계입니다.

## 4. 2단계 ② — 정렬 (RLHF)

두 번째가 **정렬**입니다. 대표적인 방식이 사람의 선호로 학습하는 **RLHF(Reinforcement Learning from Human Feedback)** 입니다.

```text
같은 질문 → 모델이 답 A, B 생성 → 사람이 더 나은 쪽 선택
         → 선택을 모아 '보상 모델'(무엇이 좋은 답인지 판단) 학습
         → 그 선호 방향으로 모델을 미세조정
```

그 결과 모델은 **도움이 되게, 해롭지 않게, 정직하게** 행동하도록 다듬어집니다. 중요한 점: 위험한 요청을 거절하는 **거부(refusal)** 능력도 바로 이 단계에서 생깁니다. 그래서 **이 단계가 풀리면 거부도 함께 풀립니다.**

## 5. 정렬이란 — 도움·안전·정직의 균형

정렬(alignment)은 모델을 사람이 원하는 방식으로 행동하게 맞추는 과정이고, 보통 세 가지를 지향합니다.

| 지향 | 의미 |
|---|---|
| **도움(helpful)** | 요청을 유용하게 수행 |
| **안전(harmless)** | 해로운 요청은 거부 |
| **정직(honest)** | 모르는 걸 지어내지 않음 |

이 셋은 자주 충돌합니다. 도움을 끝까지 밀면 위험한 요청까지 돕게 되고, 안전을 끝까지 밀면 멀쩡한 질문도 거부해 버립니다. 그 사이의 균형점을 **사람의 선호**로 잡는 게 정렬입니다.

:::caution 핵심
**거부는 모델이 타고난 성질이 아니라 '학습된 행동'이다.** 학습된 것은 되돌려질 수도 있다. 바로 이 지점이 보안으로 이어진다.
:::

## 6. 정렬은 어떻게 깨지나 — 세 가지 경로

| # | 경로 | 무엇인가 | 가중치 변화 |
|---|---|---|---|
| 1 | **탈옥(jailbreak)** | 입력 프롬프트를 교묘하게 짜 거부를 우회 | 없음 (행동만 비껴남) |
| 2 | **파인튜닝 되돌림** | 오픈웨이트 모델을 재학습해 정렬 층을 벗겨냄 | 있음 ([파인튜닝 심화](./finetuning-lora.md)) |
| 3 | **분포 이탈(OOD)** | 학습 때 못 본 언어·형식·맥락에서 정렬이 미작동 | 없음 (입력이 분포 밖) |

세 경우 모두 **'정렬은 조건부'** 라는 같은 약점을 찌릅니다.

:::info 범위
이 문서는 세 경로의 **구조**를 이해하는 것이 목적이며, 작동하는 공격 방법·페이로드는 다루지 않습니다.
:::

## 7. 왜 이렇게 쉽게 깨지나 — 표층 정렬

한 가지 설명은 정렬이 **표층(shallow)** 일 수 있다는 것입니다.

```text
┌─────────────────────────────────────────┐
│   정렬 층 (얇음, 특정 입력 분포에서만 작동)   │  ← 압력 받으면 갈라짐
├─────────────────────────────────────────┤
│   사전학습으로 얻은 거대한 능력 (그대로 남음)  │  ← 사라지지 않음
└─────────────────────────────────────────┘
```

사전학습으로 얻은 거대한 능력은 정렬 뒤에도 그대로 남아 있습니다. 정렬은 그 위에 얹힌 얇은 층이고, 특정한 입력 분포에서만 작동하는 경우가 많습니다. 그래서 탈옥이든 재학습이든 분포 이탈이든 **압력을 받으면 이 얇은 표층이 갈라지고, 아래의 능력이 그대로 드러납니다.** 정렬은 능력을 **없앤** 게 아니라 **가린** 것에 가깝고, 가림막이 얇을수록 더 쉽게 벗겨집니다.

## 8. 방어 — 정렬에만 기대지 말라

핵심 원칙은 분명합니다. **모델의 정렬은 1차 방어일 뿐이고 조건부**입니다. 그 바깥에 외부 가드레일을 겹겹이 둬야 합니다.

| 겹 | 역할 |
|---|---|
| **입력 필터** | 유해하거나 우회를 노리는 입력을 먼저 거름 |
| **출력 검증** | 답변을 내보내기 전에 다시 점검 |
| **권한 최소화** | 모델이 실제로 할 수 있는 일을 좁힘 |
| **모니터링·로깅** | 우회 시도를 관찰·축적 |

정렬 하나가 뚫려도 나머지 겹이 막아 주는 구조를 만드는 것입니다. 특히 가중치를 직접 내려받는 **오픈웨이트 모델**은 재학습으로 정렬을 제거하기가 더 쉬우므로, 모델을 '안전하다'고 가정하지 않고 **신뢰 경계 밖**에 두는 것이 핵심입니다.

:::danger 오늘의 교훈
정렬은 조건부다. 모델의 **선의**가 아니라, 모델을 둘러싼 **시스템의 통제**에 기댄다.
:::

## 정리

1. 모델은 사전학습으로 **능력**을, 사후학습·정렬로 **행동**을 얻는다.
2. 정렬은 도움·안전·정직의 균형이고, **거부는 2단계에서 학습된 행동**이다.
3. 정렬은 조건부라서 **탈옥·재학습·분포 이탈**로 깨질 수 있다 — 능력 위에 얹힌 **얇은 표층**일 수 있기 때문이다.
4. 그래서 방어는 정렬에만 기대지 않고 **외부 가드레일**을 겹겹이 둔다.

> **오늘의 한 줄** — 모델의 선의가 아니라, 모델을 둘러싼 통제를 믿는다.

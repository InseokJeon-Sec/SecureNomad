# 지식 증류

지식 증류(knowledge distillation)는 크고 복잡한 모델("교사")의 지능을 더 작고 효율적인 모델("학생")로 옮기는 과정이다. 오늘날 작은 오픈 가중치 모델이 파라미터 수를 훨씬 상회하는 성능을 내는 큰 이유다.

## 교사-학생 패러다임

많은 소형 모델은 원시 웹 데이터만으로 학습되지 않는다. 훨씬 큰 모델의 출력·로짓·추론 트레이스로 학습된다. 문서화된 사례는 오픈 모델이다:

- **Gemma 2**(2B·9B)와 **모든 Gemma 3 크기**는 더 큰 교사로부터 증류로 사전학습됐다.
- **Llama 3.2 1B/3B**는 사전학습 중 Llama 3.1 8B·70B의 로짓을 반영했고; **Llama 4 Maverick**은 미공개 Llama 4 Behemoth에서 공동 증류됐다.
- **DeepSeek-R1의 증류 체크포인트**는 R1이 생성한 약 80만 샘플로 파인튜닝된 Qwen·Llama 모델이다.
- **NVIDIA Nemotron-Labs 경쟁 코딩 모델**(2026년 9월)은 비공식 실행에서 IOI 2026 금메달 기준을 넘었는데, Z.ai의 MIT 라이선스 GLM-5.2에서 증류한 477,642개 추론 트레이스로 학습됐다. 이제 교사 계보가 벤더·국경을 넘으니 기록하라.

비공개 연구소는 소형 모델 레시피를 공개하지 않는다. "Claude Haiku는 Opus에서 증류", "Gemini Flash는 Pro에서 증류"는 그럴듯하되 문서화되지 않았다.

| 모델 | 역할 | 지능 원천 |
|-------|------|---------------------|
| **교사** | 큼(100B+ 파라미터, 종종 MoE) | 프런티어 규모 사전학습(공개 15T-36T+ 토큰) + 후학습 |
| **학생** | 작음(1B-30B 파라미터) | 교사의 필터링된 출력·로짓·추론 트레이스 |

## 증류의 작동 방식

### 1. 하드 라벨 증류
학생이 교사의 최종 예측(예: 질문의 답)에서 학습.

### 2. 소프트 라벨 증류(온도 스케일링)
학생이 교사의 **확률 분포**(로짓)에서 학습. 정답뿐 아니라 어떤 오답이 "거의" 맞았는지까지 알려주므로 훨씬 풍부하다.

```python
# Distillation Loss (KL Divergence):
Loss = KL_Div(Teacher_Logits / T, Student_Logits / T)
```
*T는 온도(보통 2.0-5.0).*

### 3. 온폴리시 증류
학생이 자기 완성을 샘플링하고 교사가 모든 토큰을 점수화해, RL의 온폴리시 관련성과 SFT의 조밀한 신호를 결합한다. 2025-2026년 추론 모델의 인기 있는 싼 경로가 됐지만, 그 메커니즘이 이제 논쟁 중이다: 2026년 8월 논문(arXiv:2608.31046, 9월 개정, 단일 그룹)은 교사 신호가 노이즈이며 이득 대부분이 저확률 토큰 억제에서 오고 교사 없는 방법이 이를 따라잡고 능가했다고 보고한다. 큰 교사에 비용을 내기 전에 교사 없는 기준선을 돌려라. 자세한 내용은 [RLVR과 추론 모델](08-rlvr-and-reasoning-models.md) 참고.

## 특성 vs 출력 증류

### 출력 증류(표준)
학생이 교사의 텍스트 응답을 맞춘다.
- **장점**: API로 구현이 쉬움.
- **단점**: 행동의 표면 패턴만 학습. 비공개 API는 점점 요약·암호화된 추론을 반환하므로, 원시 CoT는 보통 증류할 수 없다.
- **플랫폼 위험**: 벤더 호스팅 증류 파이프라인이 축소되고 있다. OpenAI의 저장된 완성→파인튜닝 경로는 폐기 중인 두 제품에 의존한다: Evals는 2026-10-31 읽기 전용, 11-30 종료; 셀프서브 파인튜닝은 2027-01-06 활성 고객 신규 작업 중단([파인튜닝 전략](02-fine-tuning-strategies.md) 참고). 데이터셋·평가 스위트·학생 학습을 통제 가능한 인프라에 둬라.

### 특성/은닉 상태 증류
학생이 교사의 내부 **은닉 상태**(벡터 표현)를 맞춘다.
- **요구**: 교사 가중치 접근 필요(오픈 가중치).
- **장점**: 학생이 교사의 "내부 개념 지도"를 학습해 훨씬 높은 추론 깊이에 이른다.

## 기각 샘플링을 통한 자기 증류

**핵심 추론 학습 기법.** 문헌은 기각 샘플링 파인튜닝, 전문가 반복(expert iteration), 또는 STaR이라 부른다. 모델이 새 인간 데이터 없이 개선된다:

1. **생성**: 어려운 수학/코드 문제에 여러 후보 해를 생성.
2. **검증**: 규칙 기반 시스템(컴파일러, 테스트 스위트, 계산기, 증명 검사기)이 맞은 것만 유지.
3. **증류**: 맞은 해로 이어진 사고 사슬로 모델을 파인튜닝.

**결과**: 모델이 고품질 추론 경로만 유지해 "자신을 증류"한다. DeepSeek-R1이 이 단계를 문서화한다: RL 단계 후 기각 샘플링으로 약 60만 검증 추론 샘플(+ 약 20만 비추론 샘플)을 모아 다음 SFT 라운드에 썼다. OpenAI·Anthropic은 레시피를 공개하지 않았다. 같은 아이디어의 RL 버전은 [RLVR과 추론 모델](08-rlvr-and-reasoning-models.md)에서 다룬다.

---

## 양자화 인식 증류

표준 양자화(16비트→4비트)는 작은 정확도 하락을 부른다.
**해법**: 양자화 과정 *중에* 지식 증류를 쓴다. 16비트 모델이 교사로서 4비트 모델이 오차를 최소화하도록 안내한다. 양자화 인식 학습과 함께, 이것이 벤더가 16비트 품질에 가까운 저비트 빌드를 내는 방식이다(예: Google의 QAT int4 Gemma 빌드). [양자화 심층 분석](07-quantization-deep-dive.md) 참고.

## 위협으로서의 증류: API를 통한 추출

API로 모델을 서빙하면 누군가는 증류를 시도한다. 이제 대규모로 문서화됐다:

- Anthropic의 2026년 2월 공개는 약 24,000개 사기 계정을 통한 1,600만 건 이상의 교환을 중국 3개 연구소의 증류 캠페인으로 돌렸다. 프록시 서비스가 "히드라 클러스터" 계정망(하나가 동시에 2만+ 관리)을 운영했고, 프롬프트는 완성된 답의 추론을 써내게 해 CoT 학습 데이터를 수확했다.
- Anthropic의 2026년 9월 위협 보고서(9/10 보도)는 5개 귀속 캠페인에 걸친 약 2억 건 교환을 기술했는데, 최대는 3개월간 3,500+ 계정에서 1.51억 건 이상이었다.
- 8월에 연구자들은 여러 벤더의 암호화된 추론 블록이 각 모델 계열이 하나의 암호화 키를 공유해 모델 간 재생될 수 있음을 보였다; 벤더들은 구멍을 막았다.
- 추론 숨기기는 다른 방식으로도 샌다: 2026년 9월 논문(arXiv:2609.26637)은 표준 API 기능으로 단순 커스텀 도구를 등록해 GPT-6 Astra 등 프런티어 모델에서 숨은 추론을 추출했다.

**API 운영자를 위한 설계 함의:** 레이트 쉐이핑과 계정별 행동 지문(CoT 유도 탐지 포함), 강화된 계정 검증, 정보 공유, 노출하는 추론 제한, 그리고 응답 텍스트뿐 아니라 그것을 드러낼 수 있는 모든 경로(도구 호출, 구조화 출력, 재생 블록)의 레드팀. 이 대응책들이 소비자로서 마주칠 여러 API 변화를 설명한다: 요약된 사고, 그리고 생성한 모델·대화에 묶인 사고 블록(Claude Fable 5.1·Opus 5.5·Sonnet 5.5; Sonnet 5.5 블록은 생성 계정에도 묶임).

## 면접 질문

### Q: 같은 토큰으로 처음부터 학습한 8B보다 증류된 8B가 왜 더 나은가?

**좋은 답변:**
원시 웹 데이터로 처음부터 학습(사전학습)하면 노이즈가 많아, 모델이 그 노이즈를 헤쳐 나가는 데 많은 용량을 쓴다. 반면 증류 모델은 "정제된" 커리큘럼으로 학습된다. 교사 모델이 고품질 필터로 작용해 구조화된 논리, 명확한 설명, 더 깨끗한 언어 분포를 제공한다. 본질적으로 교사는 로짓 분포를 통해 "힌트"를 주어, 학생에게 언어의 어떤 특성이 가장 중요한지 정확히 알려준다.

### Q: 비공개 API 모델을 오픈 가중치 학생으로 증류할 때의 위험은?

**좋은 답변:**
1. **모델 붕괴**: 학생이 교사 출력만 보면, 창의적·다양한 지식의 "롱테일"을 잃고 교사의 좁은 편향만 학습할 수 있다.
2. **라이선스 위반**: 대부분의 독점 모델(OpenAI, Anthropic)은 출력을 "경쟁" 모델 학습에 쓰는 것을 금하는 조항이 있다. API 출력으로 자체 모델을 증류하는 기업에 큰 법적 위험.
3. **탐지와 집행**: 벤더가 이제 증류 트래픽을 능동 탐지한다. Anthropic 2026 보고서는 CoT 유도 프롬프트 지문화와 계정망 차단을 기술하므로, 대량 교사 호출 기반 파이프라인은 프로젝트 중간에 끊길 수 있다.
4. **기대보다 적은 신호**: 비공개 API는 원시 CoT·로짓이 아니라 요약·암호화 추론을 노출하므로, 출력 증류만 하게 된다.
5. **언어적 흉내**: 학생이 실제 논리 깊이 없이 (교사처럼) 자신 있게 *들리게만* 학습해, 자신 있지만 틀린 환각으로 이어질 수 있다.

더 안전한 패턴은 허용적 라이선스(MIT·Apache 2.0)의 오픈 가중치 교사이며, 학습 행별로 교사 신원·라이선스를 기록한다.

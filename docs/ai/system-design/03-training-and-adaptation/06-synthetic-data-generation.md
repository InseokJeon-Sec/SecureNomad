# 합성 데이터 생성

업계는 웹의 고품질 인간 텍스트가 고갈되는 "데이터 벽(Data Wall)"에 부딪혔다. 합성 데이터는 이제 모델 개선의 주 엔진이며, 모든 현대 프런티어 모델 레시피의 핵심에 있다.

## "데이터 벽" 이후: 합성으로의 전환

오픈 모델의 공개 사전학습 예산은 이미 15T~36T+ 토큰에 이르고(Llama 4 혼합은 30T 초과), 합법적으로 깨끗한 고품질 인간 텍스트 공급은 그 속도로 늘지 않는다. 비공개 연구소는 총량을 공개하지 않는다.
**현실:** 후학습 세트는 이제 대부분 모델 생성(추론 트레이스, 재작성, 검증 해)이고, 사전학습의 합성 비중도 오르고 있다: Microsoft Phi-4 보고서는 **사전학습 토큰의 40%**를 합성 데이터에 배정한다. 대부분 연구소는 혼합을 공개하지 않으므로, 업계 전체의 단일 비율은 추측으로 취급하라.

| 원천 | 인간 데이터 | 합성 데이터 |
|--------|------------|----------------|
| **분량** | 고정(유한) | 무한 |
| **품질** | 가변(노이즈) | 통제 가능(정제) |
| **비용** | 높음(인간 라벨러) | 쌈(추론/GPU) |
| **편향** | 인터넷의 거울 | 수동으로 균형 가능 |

## Evol-Instruct 패턴

Evol-Instruct는 LLM이 단순 지시를 받아 더 복잡한 것으로 진화시키는 재귀 과정이다.

**진화 방향(WizardLM 논문에서):**
1. **심화(In-depth)**: 제약 추가, 질문 심화, 더 구체화, 또는 더 많은 추론 단계 요구.
2. **확장(In-breadth)**: 지시를 같은 도메인의 새롭고 드문 것으로 변이시켜 주제 커버리지 확대.
3. **제거(Elimination)**: 실패한 진화(새 정보 없음, 답할 수 없음, 진화 프롬프트의 복사본)를 학습 세트에 들어가기 전에 폐기.

```python
# Simple Instruction: "Write a function to add two numbers."
# Evolved Instruction: "Write a thread-safe Python class that performs 
# matrix addition with error handling and unit tests, adhering to PEP8."
```

## Constitutional AI & AI 피드백(RLAIF)

Anthropic이 개발해 업계에 널리 채택된 RLAIF는 "헌법"(규칙 집합)을 써서 모델이 자신의 데이터를 평가·개선하도록 안내한다.

**루프:**
1. **제안**: 모델 A가 응답 생성.
2. **비평**: 같은 모델이나 별도 심판이 헌법 원칙에 비춰 결함 식별.
3. **수정**: 모델 A가 비평에 기반해 더 나은 버전 생성.
4. **학습**: 최종 (프롬프트, 수정) 쌍을 SFT 세트에 추가.

## 검증 가능 합성 데이터

합성 데이터의 가장 큰 위험은 **모델 붕괴**(모델이 자기 실수를 학습)다.
**표준 해법**: LLM 없이 "진실"이 검증 가능한 영역에 집중.

- **수학**: 형식 검증(Lean/Isabelle)이나 Python 실행으로 답 검증. 형식 검사는 이제 아주 긴 기계 생성 출력으로 확장된다: Anthropic은 내부 모델이 Lean으로 페르마의 마지막 정리를 11일에 약 1,300만 줄로 형식화했고 Lean이 결과를 검증했다고 보고한다(벤더 보고, Kevin Buzzard 검토).
- **코드**: 생성 코드를 테스트 케이스(단위 테스트)로 실행.
- **RAG**: "골드 컨텍스트"로 답이 텍스트에 명시된 질문을 생성.

## 편향 제거와 다양성

합성 데이터는 인간 데이터의 "틈을 메우는" 데 쓰인다.
- **언어**: 개념 템플릿을 번역해 저자원 언어(스와힐리어, 마라티어 등)의 고품질 텍스트 생성.
- **논리**: 특정 논리 오류의 100만 변형을 만들어 모델을 그에 "강화".

## 출처와 라이선스

모든 합성 행은 그것을 생성한 모델의 의무를 상속한다.

- **교사 조건**: 비공개 모델 조건은 보통 출력으로 경쟁 모델 학습을 금하고, 벤더는 이제 대량 CoT 수확 트래픽을 탐지한다([지식 증류](05-knowledge-distillation.md) 참고). 오픈 교사는 다양하다: MIT·Apache 2.0은 깨끗; 커스텀 라이선스(Kimi K3, Qwen Community 1.0)는 호스티드 제품에 조건을 더한다.
- **계보가 국경을 넘는다**: NVIDIA 경쟁 코딩 연구 모델(비공식 실행에서 IOI 2026 금 기준 초과)은 Z.ai GLM-5.2에서 증류한 477,642개 트레이스로 학습됐다. GLM-5.2의 MIT 라이선스가 이를 허용하지만, 컴플라이언스 팀은 여전히 어떤 모델이 데이터에 닿았는지 물을 것이다.
- **행별로 기록하라**: 생성 모델·버전, 그 라이선스, 프롬프트 템플릿, 그것을 수락한 검증기, 파생된 시드 코퍼스. 법원이 적법한 학습과 원자료의 불법 취득을 분리하고 있으므로, 시드 데이터의 취득 기록이 생성기 라이선스만큼 중요하다.

## 면접 질문

### Q: 합성 데이터로 학습할 때 "모델 붕괴" 위험은?

**좋은 답변:**
모델 붕괴는 모델이 자신의 이전 버전이 생성한 데이터로 학습될 때 발생한다. 모델 분포가 실세계보다 좁으므로(특정 단어·패턴 선호/편향), 학습 루프가 오류와 밋밋함의 "양의 피드백 루프"가 된다. 표준 완화책:
1. "골든" 인간 검증 데이터 5-20% 섞기.
2. "검증 가능" 보상(수학/코드)을 써서 실수가 결코 학습되지 않게.
3. 더 강력한 "교사" 모델로 "학생" 데이터 생성.

### Q: 1,000만 행 합성 데이터셋의 *품질*을 어떻게 보장하나?

**좋은 답변:**
**다단계 필터링 파이프라인**을 쓴다:
1. **의미 중복 제거**: 임베딩으로 거의 동일한 클러스터 제거.
2. **LLM-as-Judge**: 데이터 1%를 샘플링해 더 강한 모델이 논리·안전을 점수화, 심판은 먼저 소규모 인간 라벨 세트로 보정.
3. **퍼플렉시티 필터링**: 소형 모델로 텍스트 퍼플렉시티 계산. 너무 높으면(횡설수설) 또는 너무 낮으면(반복/단순) 폐기.
4. **검증 가능 실행**: 데이터에 코드·수학이 있으면 로컬 컴파일러/인터프리터 검사 통과 필수.

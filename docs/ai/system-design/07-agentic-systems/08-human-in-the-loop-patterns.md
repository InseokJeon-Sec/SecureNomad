# 휴먼 인 더 루프 패턴

100% 신뢰할 수 있는 에이전트는 없다. **휴먼 인 더 루프(HITL)** 는 고위험 환경에서 안전·정확성을 보장하는 다리다. 프로덕션 스택이 "승인 버튼"을 넘어 **공동 추론**·**인터럽트 기반 조종**으로 옮겨가 LangGraph(인터럽트+재개)·Microsoft Agent Framework 같은 프레임워크에 네이티브 노출. 더 큰 2026 전환은 **정책 게이트 자율성**: 분류기·규칙 엔진이 어느 행동이 돌고 거부되고 인간을 위해 멈출지 결정해, 사람이 모든 호출을 클릭하는 대신 중요한 소수만 검토.

## HITL 스펙트럼

| 패턴 | 에이전트 자율성 | 인간 역할 | 적합 |
|---------|---------------|------------|----------|
| **Human-in-command** | 낮음 | 모든 단계 운전 | 고위험 법률·의료 |
| **Human-as-filter** | 중간 | 최종 출력 승인·편집 | 콘텐츠 생성 |
| **Human-as-backup** | 높음 | 오류에만 개입 | 고객 지원 |
| **Human-on-the-loop** | 최대 | 완료 후 로그 감사 | 고볼륨 분석 |

---

## 인터럽트와 브레이크포인트

현대 아키텍처(LangGraph, Microsoft Agent Framework)는 **결정적 브레이크포인트** 사용.

- **패턴**: 특정 민감 도구 호출 전(예: `execute_purchase`·`delete_user`) "일시정지"하도록 하드코딩.
- **결정**: 환경이 사용자의 `approve`·`reject` 신호를 기다림.
- **상태 보존**: 인간이 행동할 때까지 에이전트 추론 상태를 DB에 "동결". 재시작·배포를 버티려면 내구 워크플로에 일시정지 보유([내구 실행](11-durable-execution.md) 참고); MCP 도구 호출 내 승인엔 스테이트리스 2026-07-28 리비전이 `input_required` 반환·클라이언트 재시도에 재개([도구 사용과 MCP](03-tool-use-and-mcp.md) 참고).
- **턴이 아니라 행동을 게이트**: 모델이 이제 턴당 여러 행동 방출(Claude 컴퓨터 사용 툴셋이 배치를 순서대로 돌리고 첫 실패에 멈춤)해, 한 모델 왕복이 다단계 중대 행동을 완료할 수 있고 배치 전체를 승인하면 아무도 안 본 단계를 승인하는 것. 도착 시 배치 내 모든 행동을 검사하고 각 중대 행동 실행 전 확인 실행, 배치 중간 것 포함; Anthropic 컴퓨터 사용 문서가 각 블록 실행 전 검사를 둠. 거부가 배치 종료: 남은 행동을 미실행으로 답해 모델이 알려진 상태에서 재계획.

## 정책 게이트 자율성

행동별 승인은 확장 안 되고, 증거는 인간이 검토해도 약한 필터라 말함: Anthropic의 1,053명 유료 테스터 블라인드 연구(2026-08-14 분류기 기반 자동 모드를 Pro·Max·Team 플랜 Claude Code 기본으로 만들 때 인용)에서 인간이 바꿔치기된 위험 명령을 13.6% 잡았고 자동 모드 분류기는 89% 차단. 벤더가 기본값을 "매번 묻기"에서 "정책이 결정, 인간이 예외만 봄"으로 옮김:

| 제품(2026) | 게이트 작동 방식 |
|---|---|
| **Claude Managed Agents** 자동 권한 정책(9/10) | 서버가 각 에이전트·MCP 도구 호출 평가·실행·거부·승인 일시정지; 결과가 이벤트의 `evaluation` 필드에, `ant beta:sessions connect`가 라이브 승인 터미널 연결 |
| **Claude Code** 자동 모드 | 서버 측 분류기; 2.1.284(9/28)부터 권한 모드 미설정 인터랙티브 세션이 자동 모드로 시작 |
| **OpenAI dots**(9/29 발표) | 내장 규칙 + Custom Rules(행동별 허용·차단·승인 요구); 계정 영향·정보 공유 가능 행동은 자동 검토; 유휴 시 dot은 읽기 전용 리서치만 |
| **OpenAI Agents API** 컴퓨터 사용(9/29) | 각 새 웹사이트 오리진에 명시 `browser_origin_access` 승인 필요(네트워크 접근 활성은 불포함); 로그인은 별도 UI로 가 자격증명이 모델 입력에 안 들어감 |
| **GitHub Copilot** 컴퓨터 사용(공개 프리뷰, 10/1) | 애플리케이션별 승인, 검토·재설정 가능 영구 부여와 조직 수준 킬 스위치 |

관련 프리미티브는 **결정 모델**: 텍스트 생성 대신 고정 답 집합을 점수하는 모델, 게이트가 필요한 바로 그것. OpenAI Decisions API(제한 프리뷰, 9/29)가 Luna 모델로 입력 분류·요청 라우팅·에이전트 행동 선택; Cloudflare Clef(10/1, Apache 2.0)가 사전정의 답에 확률 반환해 시스템이 행동·연기, Qwen3.8-27B 베이스에서 중앙값 209ms·Clef-flash 39ms. 인간이 더 이상 루프에 필요 없다는 Cloudflare 프레이밍은 벤더 주장; 방어 가능한 용도는 인간 앞 싼 1차 게이트.

**AI 승인이 이제 인간 게이트를 만족할 수 있다.** 2026-09-01부터 Copilot 코드 리뷰가 저장소 필수 승인 규칙에 카운트되는 승인 제출 가능(공개 프리뷰, 기본 끔, 파일 경로 범위, 새 커밋에 인간 승인처럼 해제). 에이전트가 변경을 썼을 때 다른 모델 승인이 브랜치 보호를 만족하게 하면 2인 규칙이 0인 규칙이 됨. 인증·결제·인프라·에이전트 자체 구성에 닿는 경로엔 인간 승인 최소 하나 유지, AI 승인은 잘못된 머지가 되돌리기 싼 곳만 허용.

**소리 내 말할 단서:** 권한 분류기는 편의 계층이지 봉쇄가 아님. Johann Rehberger가 2026년 8월 자동 모드 우회(5회 소표본 중 3-4회 성공한 "혼란 환경" 체인)를 보였을 때 Anthropic 응답은, 그의 보고에 따르면, 자동 모드가 "보안 보장이 아니라 best-effort 분류기 뒷받침 편의 기능"이고 진짜 경계는 OS 격리·네트워크 이그레스 통제라는 것. 모든 정책 게이트를 [에이전트 보안](09-agentic-security-and-sandboxing.md)의 샌드박싱과 짝지어라.

## 승인 세탁

인간이 주는 승인은 본 것과 돌아가는 것 사이 결속만큼만 좋다. 2026-09 논문(arXiv 2609.38983)이 **승인 세탁** 정의: 코딩 에이전트 하네스가 실행하는 행동이 인간이 승인한 행동과 다름. 여섯 부류(범위·인자·시간·도구·위임·의미) 명명, Claude Code `PreToolUse` 승인 지점에서 측정. 암호 승인 토큰을 118 실행 쌍 리플레이로 검사해 위임 세탁과 논문의 시드 시간 케이스를 없앴으나, 설계상 범위 세탁은 그대로 두고 인자 세탁을 유의하게 못 줄임 — 필드 수준 검증기가 관찰할 수 있는 한 프로세스 수준 아래서 갈리기 때문.

구축할 것:
- **승인을 정확한 정규 행동에**(도구·인자·타깃·세션) 해시·서명 토큰으로 결속, 실행 시 재검증.
- **실행 형태를 인간에게 보여줘라**, 모델 설명이 아니라.
- **승인을 빨리 만료**시키고 한 세션·한 에이전트 신원으로 범위 지어 서브에이전트가 리플레이 못 하게.
- **샌드박스 유지.** 서명 승인도 틈을 남기니 승인은 위험을 줄이지 격리를 대체 안 함.

## 타임트래블 디버깅(상태 편집)

표준 에이전트는 "일방향". 3단계에서 실수하면 세션이 보통 망가짐.
- **혁신**: **상태 주입**. 인간 검토자가 3단계 상태로 "돌아가" 에이전트 관찰·사고를 편집하고 "재개".
- **영향**: 인간이 0에서 시작 않고 에이전트를 나쁜 경로에서 "조종".
- **관찰·계획을 편집, 사고는 아님.** 최신 Claude 모델에선 사고 블록이 생산 모델·대화에 묶이고 이전 사고가 프리픽스와 안 맞는 요청이 거부될 수 있음. 체크포인트로 되감아 관찰이나 쓰인 계획을 편집하고 편집점 후 사고는 재작성 않고 드롭.

## 공동 추론(공유 스크래치패드)

인간이 "심판"이 되는 대신 **"파트너"**가 됨.
- 에이전트가 **스크래치패드**(내부 사고)를 인간에게 보임.
- 특징: *"사실 B 때문에 도구 A를 쓸 계획입니다. 맞아 보이나요?"*
- **이점**: 추론 오류가 행동으로 번역되기 *전* 잡기.
- **원시 사고가 아니라 계획을 공유.** 프런티어 API가 더 이상 원시 CoT를 안 돌려줌: OpenAI가 추론 요약 반환, 최신 Claude 모델에선 기본 `display: "omitted"`에서 사고 블록이 빈 채 도착(텍스트 반환 display 모드 옵트인 안 하면). 에이전트가 검토할 명시 계획·근거를 쓰게 하고, 전사가 아니라 에이전트의 추론 설명으로 다뤄라.
- **계획을 팀이 이미 일하는 곳에.** Asana 에이전트(2026-09-29 기술)가 리서치 계획과 수행 단계를 공유 과제에 게시해 검토자가 실행 중간 코멘트·조종, 관리자·편집자만 그 피드백을 에이전트 영구 공유 메모리에 커밋 가능.

## 신뢰 기반 에스컬레이션

각 중대 단계에 **불확실성 점수** 계산.

- 점수가 임계 초과면 에이전트가 **자동 일시정지**하고 인간 운영자에 알림.
- **점수 출처가 바뀌었다.** 토큰 logprob이 프런티어 API에서 사라짐(GPT-6 Astra가 logprobs·temperature·top_p 미노출), 언어화 신뢰는 보정 나쁨. 현 패턴은 별도 보정 스코어러: 고정 결과 집합(진행·질문·에스컬레이션)에 확률 반환하는 결정 모델·분류기, 라벨 케이스에 튜닝된 연기 임계.
- **예**: 복잡한 청구 분쟁 해결 시도 에이전트가 사용자 의도가 모호함을 깨달음. 멈추고 말함: *"이 특정 환불 케이스를 어떻게 다룰지 100% 확신 못 합니다. 인간 전문가가 볼 수 있게 잠시만요."*
- **에스컬레이션은 제품 데이터.** Anthropic의 Claude Managed Agents 인바운드 세일즈 에이전트(2026-09-30 기술)가 각 대화를 체크아웃·빠른 답·담당자 핸드오프로 전체 대화 *와 왜인지 설명*과 함께 종료. Anthropic 보고(벤더): 리드-기회 전환율 2배 이상, 거래 약 5일 빨리 마감, 인간 필요 대화 비율 약 절반. "왜" 필드가 에스컬레이션 큐를 투기장이 아니라 피드백 루프로 만듦.

## 면접 질문

### Q: 인간 운영자를 "피로"시키지 않는 HITL 시스템을 어떻게 설계하나?

**좋은 답변:**
**임계 튜닝** 사용. 모든 행동에 승인을 안 묻는다. HITL은 1) 고위험 "쓰기" 도구, 2) 저신뢰 추론 단계, 3) 비즈니스 "정책" 위반 행동에만 트리거. 추가로 인간에게 **문맥 요약** 제공: 전체 로그 대신 에이전트가 하려는 1문장 "디프"를, 모델 설명이 아니라 정규 행동에서 생성해 보임. "검토 인지 부하"를 분에서 초로 줄임. 2026년 더 큰 레버는 일상 결정을 정책 게이트(Claude Managed Agents 자동 권한 정책, OpenAI dots Custom Rules)로 옮겨 인간이 예외만 보는 것.

### Q: HITL의 "과의존" 위험과 완화법은?

**좋은 답변:**
과의존은 인간이 로그를 안 읽고 "승인"을 누르기 시작할 때 발생. 측정 가능: Anthropic 블라인드 연구에서 인간 검토자가 바꿔치기된 위험 명령을 13.6%만 잡음. **강제 검토 체크포인트**(예: 인간이 제안 계획에서 최소 한 단어 편집해야)나 **합성 오류 주입**(의도적으로 1% 시간 "틀린" 계획을 보여 잡는지 확인)으로 완화. "함정"을 통과하면 계속, 실패하면 추가 교육 플래그. 인간 포착률이 이리 낮으니 되돌릴 수 없는 행동의 유일한 통제가 승인이 되게 안 함; 샌드박스·정책 게이트 위에 앉음.

### Q: 실행·거부·인간 연기할 수 있는 분류기로 에이전트 행동을 게이트한다. 연기 임계를 어떻게 설정·모니터하나?

**좋은 답변:**
비대칭 비용의 보정된 결정 문제로 다룬다. 오프라인에서 실제 행동 수백 개에 신중한 검토자의 결정을 라벨, 보정 확인(0.9가 90% 맞음을 뜻하나?), 잘못된 자동 승인의 기대 비용(폭발 반경 가중)이 인간 검토 비용과 같은 임계 선택. 임계가 행동 부류마다 다름: 읽기 전용은 관대, 쓰기는 엄격, 되돌릴 수 없거나 외부 대면은 점수 무관 항상 연기. 온라인에서 네 신호 모니터: 연기율(급상승은 드리프트·공격), 연기 항목 인간 오버라이드율(99% 승인이면 임계 너무 빡빡해 검토자가 안 읽게 됨), 자동 승인 행동 샘플 감사(거짓 승인을 보는 유일한 방법), 게이트 추가 지연. 모든 모델·프롬프트 변경에 재보정, 새 에이전트 모델이 분류기 하 행동 분포를 이동시키니. 그리고 분류기를 보안 경계로 제시 안 함; Anthropic이 자기 자동 모드 분류기를 best-effort 편의 계층이지 보안 보장 아니라 기술.

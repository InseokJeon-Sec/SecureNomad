# 비용 최적화 플레이북

AI 비용은 더 이상 "마법"이 아니다. 측정 가능하고 예측 가능하며 고도로 최적화할 수 있다. 토큰당 API 가격은 중·하위 티어에서 계속 떨어지고(2026년 9월 GPT-6 Sol $2/$10, GPT-6 Luna $0.10/$0.50/1M가 GPT-5.6 Sol·Luna의 정가를 최소 반값으로, Claude Opus 5.5가 Opus 티어를 $4/$20로 인하), GPU 렌탈 가격은 2026년 내내 올랐다. 그래서 비용 레버는 대개 더 싼 공급자 선택이 아니라 *라우팅*, *캐싱*, *서비스 티어 선택*이다. 이 장은 품질을 희생하지 않고 추론 비용을 10배 줄이는 전략을 다룬다.

## AI의 단위 경제

성공은 주어진 품질 기준·지연 SLO에서 **달러당 토큰($)** 으로 측정한다.

| 구성요소 | 비용 동인 | 최적화 |
|-----------|-------------|--------------|
| **연산** | GPU 시간($/시) | 더 나은 활용(배칭). |
| **VRAM** | KV 캐시 크기 | GQA, 양자화. |
| **네트워크** | 페이로드 크기 | 압축, 로컬 서빙. |
| **API** | 토큰당 가격 | 캐싱, 모델 선택, 서비스 티어. |

---

## 모델 캐스케이딩(효율 티어)

가장 효과적인 비용 절감 전략은 **과제를 수행할 수 있는 가장 싼 모델**을 쓰는 것.

**캐스케이드 패턴**(2026-10-01 기준 1M 입력/출력 토큰 정가):
1. **분류기**: 초소형 모델(0.5B)이 쿼리 복잡도 판정($0.00).
2. **티어 1(소형/저가)**: 쿼리 90%(인사, 단순 Q&A, 추출)는 GPT-6 Luna($0.10/$0.50), DeepSeek V4.1-Flash, 또는 자체 호스팅 소형 모델($).
3. **티어 2(중형)**: 쿼리 9%(복잡 추론)는 Claude Sonnet 5.5($2/$10), GPT-6 Sol($2/$10), 또는 Gemini 3.8 Flash(2026-12-31까지 도입가 $0.75/$3.75; 2027-01-01부터 $1.50/$7.50)($$$).
4. **티어 3(프런티어 추론)**: 쿼리 1%(전문가급)는 Claude Opus 5.5($4/$20), GPT-6 Astra($10/$50), 또는 Claude Fable 5.1($10/$50)을 높은 추론 노력으로($$$$$).

**순 결과**: 전 트래픽을 티어 2로 보내는 것 대비 80% 비용 절감.

**캐싱이 티어 단조성을 깬다.** Opus 5.5는 캐시 입력을 0.05배($0.20/1M)로 읽는데, 이는 Sonnet 5.5의 0.1배 캐시 읽기와 같은 절대가다. 긴 캐시 문맥을 재독하는 에이전트 루프에선 Opus 5.5가 캐시 안 된 Sonnet 트래픽보다 쌀 수 있다. 정가 입력이 아니라 캐시 적중률 포함 과제당 *유효* 비용으로 캐스케이드하라.

## 프로덕션용 소형 언어 모델(SLM)

소형 오픈 모델(IBM Granite 4.2 3B·8B, Gemma 4 12B, Qwen3.8-27B)과 가장 싼 API 티어(GPT-6 Luna, Claude Haiku 4.5)는 이제 대부분 벤치마크에서 2023년 원조 GPT-4를 맞먹거나 능가한다.

> 번역 주: 원문은 외부 자료로, 기업명(IBM 등)·모델명은 원문 표기를 충실히 유지합니다.

- **사용처**: 엔티티 추출, 감성 분석, 단순 RAG, 라우팅.
- **비용**: $10/$50 상한 티어(Claude Fable 5.1, GPT-6 Astra) 대비 토큰당 약 10배(Claude Haiku 4.5)~100배(GPT-6 Luna $0.10/$0.50) 저렴; 자체 호스팅 소형 모델은 높은 활용에서만 더 내려감.
- **지연**: 짧은 출력에 100ms 미만 응답.

### 가격 바닥: GPT-6 Luna와 DeepSeek V4.1-Flash

DeepSeek V4 Flash(2026-04-24 출시)는 출시 때 $0.14/$0.28/1M로 바닥을 재설정. 이후 가격이 움직였다. DeepSeek은 2026-08-16 피크·오프피크 과금 도입, 이어 **V4.1-Flash**(`deepseek-flash`, 9/10)를 피크 $0.30 입력/$1.20 출력, 오프피크 반값($0.15/$0.60), 캐시 적중 피크 $0.006·오프피크 $0.003로 출시. 피크는 평일 UTC 01:00-04:00·06:00-10:00(중국 공휴일 제외)이라 주말은 전부 오프피크. **V4-Pro**(V4-Pro-0813)는 피크 $1.32/$3.96, 오프피크 $0.66/$1.98로 유지; 9/14 예정이던 V4-Pro→V4.1-Flash 재라우팅은 9/11 철회.

가장 싼 폐쇄 티어가 이제 이를 하회: **GPT-6 Luna** $0.10/$0.50(캐시 입력 $0.01)가 오프피크($0.15/$0.60)에도 V4.1-Flash의 캐시 안 된 입출력 가격을 이긴다. DeepSeek의 남은 우위는 캐시 적중가($0.006 피크/$0.003 오프피크 vs Luna $0.01)와 자체 호스팅 가능한 MIT 가중치. 대량 배치 작업의 실무 바닥은 "GPT-6 Luna, 또는 캐시 중심 작업(공유 지식베이스 RAG, 코드베이스 에이전트)은 오프피크 스케줄된 DeepSeek V4.1-Flash"이며, 과제의 평가 품질로 고른다. 커밋 전 [DeepSeek 가격 페이지](https://api-docs.deepseek.com/quick_start/pricing)·[OpenAI 가격 페이지](https://developers.openai.com/api/docs/pricing) 확인.

## 서비스 티어와 가격 배수

같은 모델이 이제 티어만으로 약 12배 가격 범위를 가지므로, 비용 모델엔 토큰당 가격 하나가 아니라 워크로드 부류별(인터랙티브, 에이전트 내부 루프, 오프라인) 티어 정책이 필요하다.

| 레버 | Standard 대비 배수 | 어디서(2026-10-01 기준) |
|-------|------------------------|-------------------------------|
| **Batch/Flex** | 0.5배 | OpenAI Batch·Flex, Gemini Batch·Flex, Bedrock Flex, Anthropic Batch; OpenRouter Batch API(9/22)는 70+ 모델에 보통 50% 할인, 베타 중앙값 7분 완료 |
| **오프피크 스케줄링** | 0.5배 | DeepSeek 오프피크·주말 |
| **캐시 읽기** | 보통 0.1배; Opus 5.5·GPT-6.1 Sol 0.05배; Fable 5.1 0.025배 | 모든 주요 API; 쓰기는 Anthropic·OpenAI GPT-5.6+에서 1.25배 |
| **Priority/Fast** | 약 1.75배~2.5배 | OpenAI Fast 2배(GPT-5.5는 2.5배); Gemini Priority 약 1.8배; Bedrock Priority 1.75배; Opus 5.5 Anthropic 고속 모드 $8/$40(연구 프리뷰, Claude API 전용) |
| **Ultrafast** | 6배 | OpenAI, 2026-09-29부터 GPT-6 Astra에 GA(Bedrock의 Astra에도 제공) |
| **장문맥** | 전체 요청 재가격 | OpenAI는 272K 입력 초과 시 전체 요청을 장문맥 요율로(GPT-6 Sol $4/$15); xAI는 200K+에서 전 토큰 2배; Anthropic은 Claude 4.6 이후 1M까지 균일 |
| **데이터 레지던시** | 약 1.1배 | Anthropic `inference_geo: "us"`, OpenAI 레지던시 엔드포인트, Bedrock·Google Cloud 지역 Claude, Mistral EU |

함정 둘: 장문맥 추가요금은 임계를 넘으면 *전체* 요청에 적용되므로, 280K 토큰 GPT-6 Sol 프롬프트를 270K로 줄이면 입력 요율이 반, 출력 요율이 1/3 줄어든다. 그리고 프로모션 가격(Gemini 3.8 Flash 도입가, 2026-11-21까지만 보장된 GPT-5.6 Sol 프로모)은 정가로 예산화해야 한다.

## 스팟 인스턴스 전략

비실시간 워크로드(배치 처리, 데이터 추출)엔 **GPU 스팟 인스턴스**(AWS Spot, Google Cloud Spot VM, Azure Spot) 사용.

- **위험**: GPU가 짧은 통지로 회수될 수 있음: AWS 2분, Google Cloud·Azure 약 30초.
- **완화**: 작업을 재시작 가능하게. 배치 진행 체크포인트, 멱등 요청 유지, 회수 신호 시 진행 중 요청 재큐. 공유 스토리지로 계층 KV 오프로드하는 엔진은 회수에도 프리픽스 캐시를 보존할 수 있으나, 진행 중 디코드 상태의 라이브 마이그레이션은 기대하지 말 것.

### 2026년 GPU 가격: 상승, 그리고 더 긴 약정이 더 쌈

메모리 바운드 추론 수요가 커지며 GPU 렌탈 가격이 2026년 내내 올랐다. Silicon Data B200 렌탈 지수는 2026-10-01 GPU시당 $5.86(9월 진입 시 YTD 27.6% 상승), H100 지수는 $2.77. 기간 구조가 옛 조언을 뒤집었다: 9/7 B200 지수가 3개월 약정 $5.73, 12개월 약정 $5.39라 더 길게 잠그는 게 더 쌌다. 10/1 온디맨드 정가: Lambda H100 SXM $3.99·B200 $6.69; RunPod community/secure H100 $2.69/$3.49, B200 $5.98/$6.79, B300 $6.94/$7.89. 네오클라우드 계약 조건을 꼼꼼히 읽어라; SemiAnalysis ClusterMAX 3.0은 일부 1년 약정에서 선불이 100%에 달함을 지적.

## "토큰세" 최적화

- **프롬프트 캐싱**: 프리픽스를 바이트 안정하게(상단 근처에 타임스탬프·사용자별 ID 금지, 안정된 도구 순서) 유지해 반복 문맥이 캐시 읽기 요율로 과금: 대부분 모델 0.1배, Opus 5.5·GPT-6.1 Sol 0.05배, Fable 5.1 0.025배.
- **에이전트 비용은 입력이 지배**: Anthropic Claude Code 텔레메트리(2026-09-24, 벤더 보고)는 입력:출력 토큰 비가 189:1→324:1로 상승함을 보임. 그 비율에선 출력가가 아니라 캐시 적중률·캐시 입력가가 비용을 몬다. Cursor는 시스템 프롬프트 약 2/3를 줄이고 도구를 동적 로드해 사용자 토큰 비용 7% 절감 보고(벤더).
- **추론 노력**: 경로별로 명시 설정. 기본값은 모델마다 다르고 버전마다 바뀜: Opus 5.5는 `medium`(Opus 5는 `high`), Sonnet 5.5·Fable 5.1은 `high`, GPT-6.1 Sol은 `medium`. 일부 신모델은 사고를 아예 끌 수 없어, 노력이 남은 다이얼.
- **출력 절단**: `max_tokens`를 엄격히 제한.
- **간결 출력 지시**: 간결한 답(과 고정 출력 스키마) 요청은 출력 토큰을 줄임; 추론 토큰이 흔히 지배하고 영향받지 않으니, 고정 비율을 가정 말고 자신의 프롬프트에서 절감을 측정하라.

## 면접 질문

### Q: AI 시스템 비용을 CFO에게 어떻게 정당화하나?

**좋은 답변:**
**효율의 ROI**에 집중한다. 첫째, "모델 캐스케이딩"으로 트래픽 90%를 1M 토큰당 $1 훨씬 아래 모델이 처리하게 한다. 둘째, "시맨틱 캐싱"과 프롬프트 캐싱으로 같은 답·같은 문맥에 두 번 지불하지 않게 한다. 셋째, 워크로드별 서비스 티어를 배정한다(오프라인 작업은 반값 배치, 우선순위는 SLO가 필요한 곳만). 넷째, "추론 쿼터"와 "차지백 모델"을 세워 각 사업부가 사용에 책임지게 한다. AI를 티어 가격의 "상품 자원"으로 다루면 "무제한 실험"에서 "예측 가능한 OpEx" 모델로 전환할 수 있다.

### Q: 자체 호스팅 단일 GPU 클러스터가 API보다 쌀 때는?

**좋은 답변:**
"교차점"은 **일정하게 높은 처리량**에서 발생하고, 대체하는 API 티어에 크게 좌우된다. 2026년 10월 입력으로 계산: Silicon Data 지수($2.77/GPU시)의 H100 2장은 월 약 $4,000로 70B급 오픈 모델에 충분. 3:1 입출력 블렌드에서 Claude Sonnet 5.5·GPT-6 Sol($2/$10)은 1M 토큰당 약 $4라 손익분기가 월 약 10억 토큰; Opus 5.5($4/$20) 대비는 약 5억. GPT-6 Luna($0.10/$0.50, 블렌드 약 $0.20) 대비는 월 약 200억 토큰, 즉 상시 초당 약 7,700토큰으로, 이는 70B 모델 2 GPU가 지속하는 한계 이상이라 가장 싼 API 티어를 가격만으로 이기지 못한다. 그리고 자체 70B는 프런티어 API와 품질이 동등치 않으니, 가장 비싼 티어가 아니라 품질 기준을 만족하는 API 티어와 비교하라. 스파이크 또는 업무시간 트래픽은 "침묵 비용 지불"을 허용하는 API로 답을 민다. API 캐시 읽기 0.1배 이하도 에이전트 워크로드의 손익분기를 더 멀리 민다. 자체 호스팅은 활용이 꾸준하고 높을 때, 데이터가 경계를 못 떠날 때, 파인튜닝 오픈 모델이 필요할 때 이기며, 2026년 GPU 렌탈 가격 상승이 기준을 더 높인다.

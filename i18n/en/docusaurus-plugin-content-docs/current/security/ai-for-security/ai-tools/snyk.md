## Overview

Snyk is a **security platform that helps find and fix vulnerabilities in code, open-source dependencies, and containers during development**.
It uses an AI engine (DeepCode AI) to detect code vulnerabilities and suggest fixes.

Where the earlier tools are offense/assessment-focused, Snyk is **defensive, helping developers write and ship code safely**. Individual developers can start on the free plan.

## Data-handling view

As a cloud-based service, code/metadata are **processed in Snyk's environment** for analysis. For enterprise adoption, review the data-handling/retention policy and on-prem/private options. <span className="badge badge--amber">Cloud</span>

## Availability

- A freemium structure: a free plan (individuals/small teams) + paid team/enterprise plans
- Supports IDE, CI/CD, and Git integration

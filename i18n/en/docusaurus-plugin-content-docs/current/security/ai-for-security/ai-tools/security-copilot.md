## Overview

Microsoft Security Copilot is a **generative-AI assistant that helps with security operations (SOC) and incident response**.
It assists with alert analysis, incident summaries, threat hunting, and writing scripts/queries in natural language, and integrates with Microsoft security products (Defender, Sentinel, etc.) and external tools.

It specializes not in offense/assessment but in **accelerating the defender's (SOC analyst's) work**.

## Data-handling view

As a cloud (Microsoft)-based service, security data is processed in Microsoft's environment for analysis. Organizations with regulatory/data-sovereignty requirements should review the data-processing location/scope. <span className="badge badge--amber">Cloud</span>

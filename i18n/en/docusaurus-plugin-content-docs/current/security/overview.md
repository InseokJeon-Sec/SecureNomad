# Security

Security documents organized by topic. Jump to a section below.

## Sections

### 🛡️ [AI for Security](/en/security/ai-for-security/overview)
Using AI (Claude) as a **tool for security work**. AI security tool comparisons (ARTEX, PentestGPT, XBOW, etc.) and vulnerability assessment labs (XSS, SQLi).

### 🔒 [Securing AI](/en/security/ai-security-assessment/overview)
Making the organization's **use of AI itself safe**. Domestic and international guidelines, threat models (OWASP LLM Top 10), assessment methodology, safe-usage guidance, and checklists.

### 📜 [PKI · Certificates](/en/security/pki-certificates/overview)
The **theory and practice** of certificates. Cryptography and digital signatures, X.509 structure, root certificates and chains of trust, TLS authentication logic, lifecycle/renewal/revocation, and hands-on OpenSSL.

# AI System Design Guide — Korean Translation

This section is an **unofficial Korean translation** of the open-source
**[AI System Design Guide](https://github.com/ombharatiya/ai-system-design-guide)**
by Om Bharatiya. The original is an in-depth reference on production AI system
design and AI engineering interview preparation (LLMs, RAG, agents, inference
optimization, and more).

# Domain 5 — Security, Compliance, and Governance for AI (14%)

> Full content in the Korean version.

- Access control (IAM), network isolation (VPC endpoints/PrivateLink), data not used to retrain FMs
- Data protection: KMS/TLS encryption, PII minimization/masking, data quality/provenance
- Data governance (Lake Formation/Glue Catalog) and model governance (Model Cards, Model Monitor)
- Compliance/audit: CloudTrail, AWS Config, AWS Artifact, data residency, GDPR/HIPAA/Korea AI Act
- Shared responsibility model: AWS (of the cloud) vs customer (in the cloud)

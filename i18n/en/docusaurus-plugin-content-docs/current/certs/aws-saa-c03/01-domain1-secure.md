# Domain 1 — Secure Architectures (30%)

The IAM section of this domain is also available as a video. — AWS Certification Essentials #2

<YouTube id="hHbAHHAQLi8" title="AWS IAM — Core Concepts and Exam Traps | AWS Certification Essentials (SAA-C03) #2" />

> Study checklist. Detailed notes to follow.

- Secure access: IAM users/groups/roles/policies, policy evaluation, least privilege, permission boundaries
- IAM Identity Center, federation (SAML/OIDC), STS temporary credentials, cross-account AssumeRole
- Organizations & SCPs, root protection, MFA, directory services (Managed AD, Cognito)
- Resource policies: S3 bucket policy, KMS key policy, VPC endpoint policy
- Network/app security: VPC subnets, security groups vs NACLs, endpoints/PrivateLink
- Threat services: WAF, Shield, GuardDuty, Inspector, Security Hub, Network Firewall, Macie
- Secrets: Secrets Manager, Parameter Store; Session Manager / bastion
- Data protection: KMS envelope encryption, CloudHSM, ACM, S3 encryption (SSE-S3/KMS/C)

# Supplement — Frequently-Tested "Edge" Services

> Study checklist. Full notes in the Korean version.

- Compute/deploy: Elastic Beanstalk, AWS Batch, App Runner, Lightsail
- App integration: API Gateway (REST/HTTP/WebSocket), AppSync (GraphQL), Amazon MQ, AppFlow
- Data/analytics: Managed Service for Apache Flink, OpenSearch, QuickSight, Lake Formation, Glue DataBrew
- Storage/migration: S3 Object Lock, S3 Access Points, Storage Gateway, DataSync vs Transfer Family, Snow Family
- DB/server migration: DMS, SCT, Application Migration Service (MGN)
- Networking: PrivateLink, VPC Peering vs Transit Gateway, Direct Connect Gateway, Route 53 Resolver
- Ops/governance: SSM (Parameter Store, Session Manager, Patch/Automation), CloudFormation, Config, CloudTrail vs CloudWatch
- Others: DynamoDB Streams, Lambda@Edge/CloudFront Functions, ECR, EventBridge Scheduler/Pipes, Cognito

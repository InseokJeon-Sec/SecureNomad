# Topics

Study notes on core IT and computer-science topics, organized by domain and built up one topic at a time. Each topic follows a consistent answer-sheet structure (overview → concept diagram → how it works → pros/cons → comparison → practice → conclusion) so it is easy to review.

## Domains
- **Software Engineering** — architecture, methodology, design
- **Database** — modeling, normalization, transactions
- **Security** — security models and principles
- **Emerging Tech** — cloud native, containers, and more

Pick a domain from the sidebar and open a topic.

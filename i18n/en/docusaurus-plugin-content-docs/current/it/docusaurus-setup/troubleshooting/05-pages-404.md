# 404 When Opening the Site After Deployment

## Symptom

Opening `https://inseokjeon-sec.github.io/SecureNomad/` shows the GitHub 404 page.

## Cause

Checking the repository showed that **`.github/workflows/deploy.yml` had not been pushed to GitHub.**

- No `.github` folder in the repository file list
- No runs in the Actions tab

Without the workflow, the build and deployment never ran, so nothing was published to Pages and a 404 was returned.

## Fix

1. Make sure `deploy.yml` is in `.github/workflows/` at the **project root**
   (not created somewhere else, such as inside `docs`)
2. Commit → **Push origin** in GitHub Desktop (committing alone saves changes only on your PC)
3. Wait for a green check in the Actions tab, then open the site again

## 404 checklist

| Where to check | Expected state |
|---|---|
| Settings → Pages → Source | GitHub Actions |
| Repository file list | `.github/workflows/deploy.yml` exists |
| Actions tab | Latest run has a green check |
| `baseUrl` | Matches the repository name, including case (`/SecureNomad/`) |
| URL | Includes the repository name at the end |
